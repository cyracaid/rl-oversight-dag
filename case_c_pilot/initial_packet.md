# 候选初始包：日记醒来字段的使用

包版本：development-0.1。未冻结，不是可运行盲测。

## 待审主张

“指定记录中的 `time_awake` 可以解释为最终醒来时间，因此适合作为计算日记推导 TST、SE 的时间边界。”

范围状态：指定记录集合尚未完成版本和键的对齐。任务组织者必须先在私有端固定集合；
不能由模型从公开计数反推集合，也不能在看过结果后更换成更有利的子集。
这项缺口使当前包不能用于正式记录级评分。

## 输出要求

分别判断：C1 问卷与映射定义；C2 指定记录的解释依据；C3 代码与执行一致性。
原主张判为 supported、contradicted 或 unresolved，列证据引用、范围、未决问题。
如改为更弱主张，保留原主张判定，并明确标出替代主张。
每次行动写要区分的解释；停止时区分证据足够、关键来源不可得、预算耗尽与执行失败。
