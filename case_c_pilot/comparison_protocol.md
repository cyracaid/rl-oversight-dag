# 四策略 pilot：冻结前执行规范

目的：区分初始证据不足、证据判断失败与证据获取失败。本案例仅作开发诊断。
本文件不报告已运行结果。当前执行状态为 blocked_on_evidence。

## 四种对照

| 策略 | 初始输入 | 行为 | 比较用途 |
|---|---|---|---|
| P0 初始直接判断 | 同一初始包 | 不申请证据，输出判断 | 新增取证有无帮助 |
| P1 固定清单 | 同一初始包 | 按 A01→A02→A03→A04→A05→A06→A07；A08 仅在解释有依据且必要时执行；每步允许有据停止 | 简单流程是否足够 |
| P2 反馈后重规划 | 同一初始包 | 每次只选下一动作或停止，依据返回调整 | 反馈能否改善行动分配 |
| P3 全证据判断 | 全部预先确定且可释放的材料 | 一次判断，不主动获取 | 判断能力诊断，不参加获取成本排名 |

P0–P2 使用同一基础模型、相同工具规则和冻结材料。P1 的动作选择固定，但最终判断仍由同一模型完成。
P3 包含全部实际可用证据，不含维护者答案、评分或不可得来源的虚构内容。
初始包如已足够，P1/P2 可有据早停；不强迫它们花完预算。

## 每步外显记录

claim_id、原主张、C1/C2/C3 判断、decision、evidence_ids、unresolved_issues、
proposed_action、stop_reason、可选 weaker_claim；只要求简短可核验理由，不收内部推理链。
所有策略运行前重置状态，禁止共享此前策略的回答或取证记录。
人工反馈、模型重试、失败请求和额外来源必须逐项记录。

## 评分与成本

先由独立评判者依据真实材料确定允许判定及必要限定，再看模型输出。
当前没有独立参考包，因此不计算正确率。
比较原主张判定、引用支持、范围约束、错误确定性、无依据补值和停止理由。
列出每题的错误类型与实际分母；单个 Case C 不提供可推广的策略排名或总体风险率。

成本分人工主动工作、等待、计算、模型调用与 token。相同资料重复读取不重复计算生产成本。
预算在计时 pilot 后固定，现阶段不填写虚构分钟数；未计时项标 unknown。
主张“更省成本”要求达到同一预定判断质量；无错误地总说 unresolved 也须检查是否错失可解子主张。

## 运行检查

- 初始包不含错误机制名、目录答案或参考结论；当前文件名仅为开发导航，不作为盲测 ID。
- 证据与评判分别挂载；当前仓库不能作为完整模型工作区。
- 记录来源版本、模型标识、可见提示、实际返回、输出与成本；不记录 API 密钥。
- 缺失材料若令 C2 不可解，仍单独评估 C1/C3；不得合并成“全题只能拒答”。
- 四策略首次试跑后，所有看过或调过的版本继续归开发；新独立问题簇另建测试集。
