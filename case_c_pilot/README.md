## 한국어 요약

현재 자료는 전달받은 집계 요약이다. 6개 중 5개 메모에 WASO가 등장하지만,
이는 최종 기상과 야간 각성의 혼동이 확인되었다는 뜻이 아니다.
원 설문지, 정확한 대상 집합, 코드 버전과 20개 메모의 사람 검토 결과가 아직 없다.
따라서 현재 판단은 **근거 불충분**이며 반증이나 수정값 확정으로 바꾸지 않는다.
이 사례는 이미 설계에 사용했으므로 개발 사례다. 향후 독립 테스트 사례로 재사용하지 않는다.

## 开跑门槛

1. 来源案例全文及版本已取得；记录集合在私有端固定，公开侧仅保留聚合范围说明。
2. 问卷与映射、计算代码、审查备注、修改日志各自明确存在性、版本和可释放视图。
3. 每个可执行行动有真实固定返回；未知状态不得伪装成确定不可得。
4. 20 行编码与目录集合对齐完成，或对应步骤真实无法执行并说明原因。
5. 参考判断和评分由独立评判者预先审议；单人开发判断不能冒充独立双人裁决。
6. 预算经过 pilot 实测再冻结；先记录人工工作、等待、计算和模型消耗，保持分开。

若只能取得聚合摘要，可做“聚合报告能支持什么”的判断诊断；不能声称已评估记录级语义核验。
