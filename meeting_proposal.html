我们要做什么

AI 已经在帮实验室洗睡眠日记、标文献、跑分析。它产出的一条条结果互相依赖：时间写反了，睡眠潜伏期就错，睡眠效率就错，结论就不可信。

人不可能全查。我们用强化学习学一个只读建议器：下一步该审哪个节点，让更少的错误走到结论。

机器不盖章 只读排序 人点裁决才有收据

数学骨架（RL 课的主菜）

1. 因果传播（DAG 上的干预）

节点真实状态 \(X_v \in \{0,1\}\)（1=正确）。沿边 \((u,v)\)：

\[ P(X_v = 0 \mid X_u = 0) = 1 - \exp(-\lambda\, w_{uv}), \quad w_{uv}\sim U(0.5,1.5),\ \lambda=0.8 \]

审节点 \(v\) = do\((X_v := 1)\)，切断出边传染。这是因果干预，不是相关。

2. MDP

\(\mathcal{S}\) = 图知识（type, conf, 下游影响, 已审否）+ 剩余预算；\(\mathcal{A}\) = 选下一个节点（或 stop）；\(\mathcal{P}\) = 审后重算下游；\(r_T = -\#\text{sink errors}\)；\(\gamma < 1\)。

3. CMDP 拉格朗日（预算不是倒计时）

\[ \max_\pi \min_{\lambda \ge 0} J(\pi) + \lambda\,(B - C(\pi)) \]

主方法现在是 GNN + 固定预算 REINFORCE；CMDP 双 critic 在做。

4. 次模贪心 (1−1/e)

选最能让可达 sink 错误下降的审阅是单调次模最大化。贪心保证最优干预集的 63%。N=500 上这个贪心把无标度图 81→3.8。

5. 信息增益奖励（设计里，还没跑）

\[ R = \alpha\, \Delta H_v - \beta\, \mathrm{Cost}(v) \]

6. 策略梯度（主方法）

\[ \nabla_\theta J(\pi_\theta) = \mathbb{E}_{\pi}\big[ \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, A_t \big], \quad A_t = G_t - b(s_t) \]

GNN 打分器：\( h_v = \tanh(W_{\text{self}} x_v + W_{\text{neigh}} \tfrac{1}{|N(v)|}\textstyle\sum_{u\in N(v)} x_u ) \)

7. 可靠性 worst-of-n

一个漏审能作废结论（HealthBench）。noise worst-of-5 = 5.20，oracle = 0.80。

为什么这不是编的

我们自己的数据：13,990 条 / 237 人，人改了 75 处（0.54%）。这 75 处里 76% 是同一种错（order_error，p<0.0001）。

错误率低，所以全审不划算；错误高度聚集，所以「审哪个」比「审多少」重要。

和 OpenAI 两个基准的关系

HealthBench（医生 rubric + worst-of-n + 共识/Hard 拆分）教我们怎么评。BioBasicsBench（原始湿实验证据 + 错误检测 + 「证据不足」）教我们 everyday science 的失败长什么样——假设压过对照，和我们 76% order_error 同一物种。

我们采纳：偏学分收据、错误检测当一等技能、「证据不足」当显式动作、三轮评审。

我们加的：预算、依赖图、延迟到结论的惩罚。他们没建这个。

What we build

AI already cleans sleep diaries, labels papers, runs analyses. Its outputs depend on each other: a flipped time becomes a wrong latency, a wrong sleep efficiency, an untrustworthy conclusion.

A human cannot check everything. We train a read-only RL suggester: which node to review next, so fewer errors reach the conclusion.

Machine never stamps read-only ranking receipt only on human verdict

Math skeleton (the RL-course main course)

1. Causal propagation (intervention on a DAG)

\[ P(X_v = 0 \mid X_u = 0) = 1 - \exp(-\lambda\, w_{uv}), \quad w_{uv}\sim U(0.5,1.5),\ \lambda=0.8 \]

Reviewing \(v\) = do\((X_v := 1)\). Causal intervention, not correlation.

2. MDP. \(\mathcal{S}\) = graph knowledge + remaining budget; \(\mathcal{A}\) = next node (or stop); \(r_T = -\#\text{sink errors}\); \(\gamma < 1\).

3. CMDP Lagrangian. \(\max_\pi \min_{\lambda \ge 0} J(\pi) + \lambda\,(B - C(\pi))\). Main method today is GNN + fixed-budget REINFORCE; dual-critic CMDP is in progress.

4. Submodular greedy (1−1/e). On N=500 this greedy takes scale-free graphs from 81 to 3.8.

5. Information-gain reward (in the design, not yet run). \(R = \alpha\, \Delta H_v - \beta\, \mathrm{Cost}(v)\)

6. Policy gradient (main method). \(\nabla_\theta J = \mathbb{E}[ \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, A_t ]\)

GNN scorer: \( h_v = \tanh(W_{\text{self}} x_v + W_{\text{neigh}} \frac{1}{|N(v)|}\sum_{u\in N(v)} x_u ) \)

7. Worst-of-n. One unreviewed error can invalidate a conclusion (HealthBench). noise worst-of-5 = 5.20, oracle = 0.80.

Why this is not made up

Our own data: 13,990 records / 237 people, 75 human corrections (0.54%). Of those 75, 76% are one type (order_error, p<0.0001).

Low error rate → reviewing everything is wasteful. High clustering → which to review matters more than how many.

우리가 만드는 것

AI가 이미 수면 일기를 정제하고, 문헌에 라벨을 달고, 분석을 돌립니다. 그 출력은 서로 의존합니다: 시간이 반대로 쓰이면 잠복기가 틀리고, 수면 효율이 틀리고, 결론이 믿을 수 없게 됩니다.

사람이 전부 확인할 수는 없습니다. 강화학습으로 읽기 전용 제안기를 학습합니다: 다음에 어떤 노드를 검토할지, 결론에 도달하는 오류를 줄이기 위해서.

기계는 도장을 찍지 않음 읽기 전용 순위 사람이 판정해야 영수증

수학 골격 (RL 수업의 메인)

1. 인과 전파 (DAG 개입)

\[ P(X_v = 0 \mid X_u = 0) = 1 - \exp(-\lambda\, w_{uv}), \quad w_{uv}\sim U(0.5,1.5),\ \lambda=0.8 \]

노드 \(v\) 검토 = do\((X_v := 1)\). 인과 개입이지 상관이 아닙니다.

2. MDP. \(\mathcal{S}\) = 그래프 지식 + 잔여 예산; \(\mathcal{A}\) = 다음 노드(또는 stop); \(r_T = -\#\text{sink 오류}\); \(\gamma < 1\).

3. CMDP 라그랑지안. \(\max_\pi \min_{\lambda \ge 0} J(\pi) + \lambda\,(B - C(\pi))\). 오늘 주 방법은 GNN + 고정 예산 REINFORCE; 이중 critic CMDP는 진행 중.

4. 준모듈러 탐욕 (1−1/e). N=500에서 이 탐욕은 스케일프리 그래프를 81 → 3.8으로 만듭니다.

5. 정보 이득 보상 (설계, 아직 미실행). \(R = \alpha\, \Delta H_v - \beta\, \mathrm{Cost}(v)\)

6. 정책 경사 (주 방법). \(\nabla_\theta J = \mathbb{E}[ \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, A_t ]\)

GNN 점수기: \( h_v = \tanh(W_{\text{self}} x_v + W_{\text{neigh}} \frac{1}{|N(v)|}\sum_{u\in N(v)} x_u ) \)

7. worst-of-n. 검토 안 된 오류 하나가 결론을 무효화할 수 있습니다(HealthBench). noise worst-of-5 = 5.20, oracle = 0.80.

이것이 만들어진 게 아닌 이유

우리 데이터: 13,990 기록 / 237명, 75건 사람 정정(0.54%). 그 75건 중 76%가 한 유형(order_error, p<0.0001).

오류율이 낮아 전체 검토는 비효율적입니다. 오류가 강하게 뭉쳐 있어 무엇을 검토하느냐가 얼마나 검토하느냐보다 중요합니다.
