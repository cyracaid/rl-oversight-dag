# 사전 등록 v2: 공유 (q, δ) 범위 모형

작성 2026-11-24, **실행 전**에 고정한다. 3600–3799 결과를 본 뒤에는 이 파일의 정의·예측·판정
기준을 바꾸지 않는다. `PREREGISTER_SCOPE.md`(v1)는 그대로 두고, 이 파일이 v1을 대체한다.

## v1을 왜 버렸는가 (설계 이력, 정직하게)

v1은 실행 전 점검에서 두 가지 결함이 드러나 폐기했다. 둘 다 **보정 블록(70040 등)** 에서만
확인했고, 3600–3799 씨드는 한 번도 실행하지 않았다.

1. **H0가 H2에 내포된다.** v1은 "아무 일도 없음"(`H0`)을 별도 가설로 두었는데, `H2`의 노드별
   항 `(1−π)L_i(0) + π·mean_δ L_i(δ)`에 이미 "이 노드는 안 움직임"이 들어 있다. 그래서
   `error_nodes` +3 처럼 일부만 움직인 그래프에서 `P(H0)`가 0.76까지 올라가 진짜 오류를 덮었다.
2. **δ 사전확률을 노드마다 지불한다.** v1의 `H2`는 노드마다 δ를 고르므로, 40개 노드가 움직이면
   `−log 16`을 40번 문다. 그래서 50 % 부분 손상에서 `H1`(전체 이동)이 0.9999로 이겨
   "전체가 조금 움직였다"는 틀린 설명을 골랐다.

두 결함의 공통 원인은 **생성기와 모형의 불일치**다. 손상 생성기는 locality 하나를 골라 그 안의
일부 비율을 **하나의 δ**로 민다(`corrupt_snapshot`). 그러므로 모형도 "δ 하나 + 비율 하나"여야
한다. v2는 그렇게 쓴다.

## 정책 `scope` (동결)

관측 가능한 것만 쓴다: 공개 점수 `c`, 노드 타입과 타입별 사전확률 `r_i`, 간선·그래프 구조.
정답(`source_errors`), 간선 동전, 검토자 난수는 쓰지 않는다. 정책 규칙·예산 16회는
`trust`/`shrink`와 동일하고, 입력 사후확률만 바뀐다.

환경의 공개 상수를 그대로 쓴다(`dag_role3/environment.py: initial_belief`).

```
z_i = logit(c_i)
bias_i = -0.4 * (r_i - 0.15)
점수 모형: z_i | b_i, δ ~ N(mu_b + bias_i + δ, SIGMA)
mu_1 = -1.5, mu_0 = +1.5, SIGMA = 1.2
δ 격자 Δ = {±0.5, ±1.0, ..., ±4.0}  (16개)
비율 격자 Q = {0.05, 0.10, 0.15, 0.20, 0.25, 0.30, 0.40, 0.50, 0.65, 0.80, 1.00}
노드별 주변우도 L_i(δ) = r_i φ((z_i - mu_1 - bias_i - δ)/SIGMA)
                       + (1 - r_i) φ((z_i - mu_0 - bias_i - δ)/SIGMA)
```

셀은 두 종류다. "아무 일도 없음" 셀 하나(`q = 0`)와, (q, δ) 셀 `11 × 16 = 176`개.

```
q = 0        우도 Π_i L_i(0)
(q, δ)       우도 Π_i [ (1-q) L_i(0) + q L_i(δ) ]
사전          P(q = 0) = p0,  P(q, δ) = (1 - p0) / (|Q| · |Δ|)
사후 가중     w_c ∝ 사전_c · 우도_c
노드 사후     q_i = Σ_c w_c · P(b_i = 1 | c),
              P(b=1 | c) = [(1-q)L_i(0)P(b_i=1|δ=0) + q L_i(δ)P(b_i=1|δ)] / [(1-q)L_i(0) + q L_i(δ)]
```

`q_i`를 `_belief_base`에 넣고 나머지는 `trust`와 완전히 같다.

핵심 성질(검증 대상): 80개 노드가 모두 같은 δ로 움직이면 `q = 1` 셀이 이기고, 노드 사후는
δ를 되돌린 값이 되어 `trust`처럼 행동한다. 일부만 움직이면 `q`가 그 비율로 추정되어 `shrink`와
비슷한 방향으로 작동한다. **이 실험은 그 가설 선택이 실제로 맞는지 재는 것이지, 임계값을
찾는 것이 아니다.**

## p0 적합 (동결)

- 보정 그래프: **70000–70029** (30개), 에피소드 시드 `graph_seed + 20000`.
- 격자: `p0 ∈ {0.20, 0.35, 0.50, 0.65, 0.80}`.
- **허용 집합** = 깨끗한 셀 평균이 `trust`보다 `+0.05` 이내인 `p0`.
- 허용 집합 안에서 **112셀 평균 잔여 오류가 최소**인 값을 고른다. 동률이면 작은 `p0`.
- 한 번만 적합하고 3600–3799에는 재적합하지 않는다.

적합 결과는 `p0 = 0.20` (깨끗한 비용 0.000, 격자 평균 1.0363). 곡선은 평평했다
(0.20–0.80 구간에서 격자 평균 차이 0.006). 즉 사전확률은 거의 중요하지 않고 우도가 가설을
정한다 — 이것도 결과로 보고한다.

## 예측 (실행 전, 3600–3799에서 채점)

1. **전체 상향 이동의 회귀를 없앤다**: uniform 100 %·+3 에서 `scope − trust ≤ +0.20`
   (shrink 는 +0.72).
2. **같은 회귀가 +2 에서도 없다**: uniform 100 %·+2 에서 `scope − trust ≤ +0.20` (shrink +0.45).
3. **은폐형에서 trust보다 나빠지지 않는다**: error_nodes 100 %·+3 에서 `scope − trust ≤ +0.20`.
   다만 여기서 shrink 의 **−0.370 이득을 잃을 것으로 예상한다**. 은폐된 그래프는 점수만 보면
   깨끗한 그래프와 구별되지 않으므로 우도가 `q = 0`을 고르고, 그러면 정책이 `trust`로 돌아간다.
   (보정 그래프 70000–70005에서 `map_q = 0`, `P(none) = 0.27–0.71`로 실제로 그랬다.)
4. **깨끗한 비용이 작다**: 깨끗한 셀에서 `scope − trust ≤ +0.05`.
5. **부분 손상에서 trust보다 나빠지지 않는다**: uniform 50 %·−3 과 25 %·−3 에서
   `scope − trust ≤ +0.10`.
6. **전체로도 손해가 아니다**: 112셀 평균에서 `scope − shrink ≤ +0.10`.

## 미리 적는 예상 손실 (실행 전)

`q = 1`이 이기는 셀에서는 δ를 되돌리므로 정책이 `trust` 쪽으로 돌아간다. 따라서
uniform 100 %·−4(shrink −0.88)와 −3(−0.66)의 이득은 **사라질 것으로 예상한다**. 그 이득은
"전체 이동을 인지하지 못해 생긴 착시"였고, 순위를 보존하는 전체 이동에서 옳은 행동은 되돌리기
때문이다. 은폐형의 −0.370도 예상 손실에 넣는다(예측 3). 이 손실들은 예측 6이 흡수하는지
여부로만 판정하며, 사후에 "역시 손해였다"고 말하지 않기 위해 지금 적는다.

## 한계 (미리 적음)

- δ 격자가 평가 격자의 이동 범위와 같다. 모형 선택의 순환 위험이 있고, 다른 손상 생성기
  (곱셈적 왜곡, 구간별 다른 δ, 노드별 임의 δ)에는 그대로 전이되지 않는다.
- q 격자는 0.05 간격(≤ 0.30), 그 위는 성기다. 참 비율이 0.35나 0.45면 이웃 셀로 흡수된다.
- 한 그래프에 δ가 하나라는 가정은 이 생성기의 것이다. 두 locality가 동시에 손상되는 조건은
  이 실험에 없다.
- `p0` 곡선이 평평해 사전확률의 영향은 작지만, 완전히 0은 아니다. 깨끗한 그래프에서
  `P(none)`이 0.4–0.6에 머무는 것은 그래프 80개가 "아무 일 없음"에 대해 주는 증거가
  생각보다 약하기 때문이며, 그 사실도 결과로 남긴다.
- 정규분포·등분산·노드 독립 가정은 이 합성 Spike 생성기의 것이다. 실제 손상은 locality 단위
  (all-or-none)라 노드 독립 가정은 증거를 과소평가하는 보수적 방향이다.
- `oracle`은 정답을 쓰므로 비배포. 단일 marginal 규칙, 단일 그래프 family, 학습 정책 없음.
- 보정 블록(70000–70029)은 v1 설계 폐기와 `p0` 적합에 사용됐다. 예측은 메커니즘에서 유도했고
  (예측 3의 은폐형 손실 예상은 보정 그래프의 `map_q` 진단에 근거), 3600–3799 수치는 보지 않았다.
