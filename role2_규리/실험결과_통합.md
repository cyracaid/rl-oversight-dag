# Role 2 검토 순서와 신뢰도 보정 실험

2026년 11월 24일 · 실험 결과 정리

합성 작업 흐름에서 같은 16회를 검토해도 어느 값을 먼저 확인하느냐에 따라 최종 결론에 남는 오류가 달랐다. 정상 신뢰도 확인 실험에서는 하류 영향을 고려한 규칙이 학습 정책보다 오류를 적게 남겼다. 점수가 손상된 일부 조건에서는 점수를 보정하는 것만으로 오류가 줄었다. **새로 시험한 같은 층의 두 이동량 조건에서는 두 보정법 모두 평균 오류를 소폭 줄였고, 두 방법의 차이는 불확실했다.**

## 1 오류가 전파되는 수면 사례

이 연구에서 오류는 사람이 검토해 정정할 수 있는 **자동 파이프라인 출력값의 오류**다. 예를 들어 기상 시각이 입면 시각보다 이르게 기록되거나, 두 시각의 차이를 잘못 계산하거나, 계산값이 수면 효율을 100%보다 높게 만들 수 있다. 수면 교정 기록 75건 중 57건이 시간 순서 오류였다. **76%는 교정 건의 유형 구성비**다. 실험에서 쓰는 노드별 오류 사전확률은 모델 설정이다.

수면 의존성 그래프(DAG)는 수집·전처리·분석·결론 4단계의 출력값 21개를 노드로 표현한다. 예를 들어 **야간 각성 시간 입력 오류 → 각성 시간 계산 → 총 수면 시간과 수면 효율 계산 → 수면 효율 판정**으로 영향이 이어진다. 한 노드에는 자체 출력 오류와 상류에서 전파된 오류가 생길 수 있다. 검토에서 자체 오류를 발견하면 해당 값을 정정하고 하류를 다시 계산한다. 정책은 숨은 정답을 모르는 상태에서 공개 점수, 그래프 구조, 검토 이력과 오류 확률 추정치를 사용한다.

| 교수님이 연결해 달라고 한 요소 | 검토 순서 모형에서의 구현 |
|---|---|
| 전문가 검토 위임 | 행동마다 아직 검토하지 않은 노드 한 곳을 선택한다. |
| 제한된 검토 예산 | 남은 횟수를 상태에 포함하고, 예산을 모두 쓰면 종료한다. |
| 하류 오류 전파 | 정정 후 의존 노드를 다시 계산한다. 종료 보상은 남은 결론 오류 수에 음수를 붙인 값이다. |

확인할 시간이 부족하면 가장 의심스러운 값과 고쳤을 때 여러 결론에 영향을 주는 값 중 어디를 먼저 볼지 정해야 한다. 검토 대상의 오류 가능성, 하류 영향, 남은 횟수를 같은 문제에 넣은 이유다.

## 2 같은 예산에서 검토 규칙과 학습 비교

Role 2의 주 벤치마크는 **합성 Spike 그래프 80노드, 검토 16회, 결론 20개**다. 모의 검토자는 검토한 노드에 자체 오류가 있을 때 기본 설정에서 90% 확률로 발견한다. 정책끼리 같은 그래프, 초기 오류, 간선 전파 난수와 검토 난수를 공유한다. 주 지표는 16회 후 그래프당 잔여 결론 오류 수다. 신뢰도순은 점수가 낮은 노드부터 보고, 하류 영향 규칙은 한 번 정정했을 때 줄일 것으로 기대되는 결론 오류가 큰 노드부터 본다.

| 질문과 평가 조건 | 관측 결과 |
|---|---|
| 정상 점수에서 학습 정책이 규칙을 앞서는가 | 확인 그래프 200개에서 신뢰도순 1.275개, 하류 영향 규칙 `marginal` 0.885개, 기존 GNN 1.262개. 짝지은 GNN − 규칙 차이는 **+0.377 [+0.255, +0.510]**개였다. 학습량 10배 비교의 차이는 +0.262 [+0.165, +0.365]개였다. |
| 점수를 믿을지 검토 결과로 갱신하면 도움이 되는가 | 유형 내 점수 섞기에서 하류 영향 규칙은 **3.820 → 3.075개**, GNN은 4.083 → 3.853개로 줄었다. 일부 유형만 섞은 다른 평가의 주 조건에서는 갱신이 점수를 계속 무시하는 정책을 앞섰고, 계속 신뢰하는 정책과의 차이는 불확실했다. |
| 학습 구조나 검토 계획을 바꾸면 규칙보다 나아지는가 | 유형 내 섞기에서 잔차 GNN − 하류 영향 규칙 **+0.022 [−0.018, +0.072]**개. 결과별 2단계 − 혼합 1단계 **+0.035 [−0.025, +0.100]**개. |
| 행동마다 보상을 다르게 주면 GNN이 나아지는가 | 같은 구조의 종료 보상 GNN **4.549개 → 검토별 보상 GNN 2.926개**. 별도 확인 그래프 200개에서 개선한 GNN은 2.945개, 2단계 규칙은 2.765개였다. 짝지은 차이는 **+0.180 [+0.021, +0.377]**개였다. |

정상 점수 개발 비교에서는 기존 GNN이 검토 중 오류를 더 자주 발견했지만(44.1% 대 36.2%), 하류 영향 규칙이 최종 오류를 더 적게 남겼다(1.130개 대 1.485개, 규칙과 GNN 순). 지표를 결론에 두면 많이 찾는 정책과 많이 고치는 정책의 차이를 볼 수 있다.

## 3 점수가 이동할 때 실패한 비교와 보정

균등 잡음에서는 그래프의 평균 점수로 어떤 신뢰도 모형을 쓸지 정하자 결론 오류가 4.415개에서 3.150개로 줄었다. 같은 유형 안에서 기존 점수를 서로 바꾸자 그래프 평균이 유지되어 이 방식으로는 손상을 알아채지 못했다. 다음 비교에서는 선택된 노드의 공개 점수가 한쪽으로 치우치는 상황을 만들었다. 이동량 δ는 신뢰도에 로그 오즈 단위로 더한 값이다.

| 방법과 조건 | 관측 결과 |
|---|---|
| 그래프 전체 평균을 보는 전역 게이트 | 순위를 보존하는 −1 이동에 200개 중 195개에서 발동했다. 실제 오류를 높은 신뢰도로 가리는 +3 조건에서는 200개 중 0개에서 발동했다. |
| 검증을 추가한 게이트 `verify` | 발동한 13조건 중 5조건에서 점수를 그대로 믿는 방식보다 결론 오류가 많았다. |
| 노드별 보정 `shrink` | 은폐형 +3에서 점수를 그대로 믿는 방식보다 0.370개 적게 남겼다. 전역 +3에서는 같은 비교에서 오류가 0.720개 더 남았다. 두 수치는 노드별 보정 평가에서 얻었다. |
| 그래프별 보정 `scope` | 전역 +3에서 `trust`보다 0.005개 더 남겼다. 같은 조건의 `shrink`는 0.810개 더 남겼다. 은폐형 +3에서는 `scope`가 `shrink`보다 0.325개 더 남겼다. |

기존 경계 실험에서 격자 밖의 단일 δ는 전체 이동 조건에서 평균 절대오차 **0.174**로 추정했다. 원천층과 결론층에 서로 다른 δ를 준 8조건에서는 `scope − shrink`의 평균 차이가 **−0.016개**였고, 조건별로 우열이 갈렸다.

검토 적중률을 바꾼 별도 합성 실험에서 `marginal`은 60%, 75%, 90%, 100%에서 모두 신뢰도순보다 결론 오류를 적게 남겼다. 우위는 **0.255 → 0.350 → 0.415 → 0.530개**로 커졌다. 낮은 적중률에서 우위가 커진다는 사전 예측과 반대 방향이었다.

## 4 같은 층에 두 이동량을 섞은 새 실험

합성 Spike 그래프 **100개(시드 4600–4699)**에서 원천층과 결론층을 각각 시험했다. 한 층의 노드 20개 중 50% 또는 100%를 골라 두 집단에 균등 배정하고, 집단마다 다른 δ를 적용했다. 층 2개, 손상 비율 2개, δ 쌍 5개로 총 20개 혼합 조건을 비교했다. 세 방식은 같은 하류 영향 규칙과 검토 16회를 사용했다. 정상 신호 대조 1개를 더해 **6,300행**을 검증했다.

| 점수 처리 | 혼합 20조건 평균 | 정상 대조 |
|---|---:|---:|
| 공개 점수 그대로 사용 `trust` | 1.7180 | 1.2000 |
| 노드별 보정 `shrink` | 1.6905 | 1.2300 |
| 그래프별 보정 `scope` | 1.6690 | 1.1800 |

혼합 조건의 사전 지정 비교는 **`scope − shrink` −0.0215개 [−0.0470, +0.0030]**였다. 20조건을 같은 비중으로 평균하고 그래프를 단위로 짝지어 재표집했다. 구간이 0을 포함해 두 보정법의 우열은 확정하기 어렵다. 보조 비교에서는 `scope − trust` **−0.0490 [−0.0865, −0.0140]**개, `shrink − trust` **−0.0275 [−0.0515, −0.0030]**개였다. 보정의 평균 효과는 이 합성 조건에서 소폭이었다.

별도의 KAIST 공개 일기 재생에서는 평가 참가자 41명의 일기 기록에 오류를 주입하고 참가자당 두 밤의 검토 순서를 비교했다. 연속 두 밤을 보거나 첫날 결과로 다음 밤을 바꾸는 방법의 추가 이득은 확인하기 어려웠다. 수면 DAG의 의존관계는 문제를 설명하고, 새 δ 실험은 합성 그래프에서 보정의 적용 범위를 측정한다.
