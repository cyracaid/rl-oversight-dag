# 신뢰도 신호가 흔들릴 때, 무엇을 먼저 검토할까?

2번의 질문은 **같은 16번의 검토로 어느 정책이 최종 결론의 오류를 더 많이 줄이는가**, 그리고 그 순위가 **신뢰도 신호를 믿을 수 있는지**에 따라 달라지는가이다. 정확한 신호와 잘못 해석된 신호에서 모두 강한 규칙과 비교한다. 이 문서는 이번 v3 개발 실험의 결과를 보기 전에 정한 비교 계획이다. [팀 연구 목적과 교수 피드백](../RL_연구요점_교수피드백_KO.md) · [2번 역할](../TEAM_CLAIMS_KO.md)

## 수면 연구에서 검토 순서가 중요한 이유

수면 DAG에서 취침 시각 `time_bed`와 입면 시각 `time_sleep`으로 두 시각의 차이 `bed_sleep_diff`를 구한다. 취침 시각을 잘못 입력하면 이 차이와 입면 지연 계산 `SOL_calc`를 거쳐 결론 `SOL_validity`까지 바뀔 수 있다. 사람의 정정 기록을 재생한 53건 중 원천 오류가 하나였던 37건에서는 결론 4개 중 평균 1.84개가 바뀌었다. 이는 정정 대상 기록에서의 수치다. [수면 DAG 정의](../role3%20improvement/dag_role3/graphs.py) · [정정 기록 재생과 적용 범위](../experiments/REPLAY_MANUAL_CORRECTIONS_INTERPRETATION.md)

| 교수 피드백의 세 요소 | 이번 합성 실험에서 관측·조작하는 것 |
|---|---|
| 사람 검토 | 정책은 공개된 신뢰도·그래프·검토 이력으로 다음 노드를 고른다. 선택한 노드가 틀렸을 때 모의 검토자가 이를 발견할 확률은 0.9다. |
| 검토 예산 | Spike 그래프 80개 노드 중 16개를 차례로 검토한다. 다음 행동을 고를 때 남은 검토 횟수와 앞선 검토 결과를 활용할 수 있다. |
| 오류 전파 | 오류를 발견하면 해당 노드의 원천 오류를 제거하고 하류 상태를 다시 계산한다. 상류 원인이 남아 있으면 오류가 계속 전파될 수 있다. 16번째 검토 후 마지막 층의 결론 20개에 남은 오류를 센다. |

## 평가 조건과 정책

평가 그래프 시드는 **91000–91199**, 총 200개로 고정한다. 모든 정책이 같은 그래프, 원천 오류, 간선별 전파 난수, 노드별 발견 난수를 공유한다. 한 그래프에서 조건을 바꿀 때도 이 값들을 유지한다. [v3 환경과 학습·검증 분할](../role3%20improvement/README_KO.md)

| 조건 | 관측되는 신뢰도 | 정책에 제공하는 오류확률 추정 |
|---|---|---|
| 정상 | 원천 오류와 연관된 신호 | 정상 신호의 생성 모형으로 계산 |
| 잡음을 정상으로 해석 | 원천 오류와 독립인 균등 난수 | 정상 신호의 생성 모형을 그대로 적용 |
| 잡음임을 알고 해석 | 위 조건과 같은 균등 난수 | 신뢰도에서 얻는 증거를 제외하고 노드 유형별 사전확률에서 출발 |

학습 정책은 v3의 GNN + REINFORCE `observed`다. 학습 시드 1·2·3에서 각각 1,000에피소드 학습 중 별도 검증 그래프로 선택한 체크포인트를 고정한다. 비교 정책은 낮은 신뢰도순 `confidence`, 유형별 원천 오류율순 `type_prior`, 추정한 원천 오류 확률과 하류 결론에 대한 영향을 결합한 v3 `marginal`이다. 유형 확률은 공개된 모형 값이다. 정책에는 에피소드의 숨은 정답을 제공하지 않는다. [기준선 구현](../role3%20improvement/dag_role3/policies.py) · [유형 사전확률 대조의 배경](../experiments/PROPOSAL_GAPS_NEXT_EXPERIMENT.md)

추가 규칙 `adaptive_marginal`은 매 그래프의 검토를 시작하기 전에 공개된 노드 신뢰도의 평균만 보고 정상 신호와 잡음 중 어느 쪽에 가까운지 추정한다. 평가 구간과 겹치지 않는 합성 그래프 100개(그래프 시드 70000–70099, 에피소드 시드 = 그래프 시드 + 20000)에서 정상·잡음별 평균을 미리 구한다. 두 모형의 사전 가중치는 같게 두고 두 평균의 중간값을 판별 경계로 사용한다. 선택한 모형으로 초기 오류확률을 정한 뒤 기존 v3 `marginal` 규칙을 적용한다. 이 규칙에는 평가 조건의 이름이나 검토 후 결과가 주어지지 않는다. 두 잡음 조건의 입력은 완전히 같으므로 이 규칙의 판별과 행동도 같아야 한다. 이는 두 합성 신호 모형에 맞춘 보정이며, 실제 수면 기록에서의 신뢰도 분포는 별도 검증이 필요하다.

## 결과를 읽는 기준

- 주 지표는 **검토 후 그래프당 평균 잔여 결론 오류 수**다. 같은 그래프에서 학습 정책의 오류 수에서 기준선의 오류 수를 뺀다. 음수면 학습 정책이 더 많은 결론 오류를 줄였다. 신뢰도 신호를 잘못 해석한 조건의 결과와 함께, **동일한 잡음에서 사전확률로 보정한 `marginal`과 학습 정책의 차이**를 본다.
- 보조 지표는 검토 1회당 발견 수와 검토 1회당 줄어든 결론 오류 수다. 발견 수가 늘어도 최종 결론 개선이 작을 수 있으므로 두 지표를 함께 읽는다.
- 시드별 차이와 세 시드의 동등 가중 평균을 보고한다. 95% 부트스트랩 구간은 학습 시드와 평가 그래프를 각각 재표집하고, 매 표본에서 정책 간 그래프 짝을 유지해 구한다. 결정적 규칙끼리 비교할 때는 그래프만 재표집한다. 학습 시드는 3개이며 여러 조건을 살피는 개발 실험이므로 구간은 불확실성의 탐색적 요약으로 해석한다.
- 세 조건 각각에서 자동 판별이 정상·잡음으로 분류한 그래프 수와 `adaptive_marginal`의 잔여 오류 수에서 같은 조건의 일반 `marginal` 잔여 오류 수를 뺀 차이를 보고한다. 이 차이의 95% 구간은 짝지은 그래프만 재표집해 계산한다.
- 잡음에서 학습 정책이 유리하더라도 유형별 규칙과 보정한 `marginal`이 얼마나 설명하는지 함께 보고한다. 정상 조건을 포함한 모든 비교를 남기고, 결과에 맞춰 성공 기준을 바꾸지 않는다.

이 실험이 직접 평가하는 대상은 합성 Spike 그래프의 노드 검토다. 수면 패널 재생에서는 한 밤에 주입한 가시적 오류에 기존 QC 규칙이 강했고, 여러 밤에 걸친 체계적 오류에서 더 큰 변화가 관찰됐다. 실제 수면 업무로 확장할 때는 연속된 여러 밤을 한 번에 검토하는 문제를 별도로 정의하고 평가해야 한다. [수면 패널 재생 결과와 한계](../experiments/CROSS_RECORD_REPLAY_INTERPRETATION.md)

## 추가 대조 실험 — 신뢰도의 분포가 그대로일 때

이 대조는 앞의 세 조건을 실행한 뒤, 집계 결과를 열어 보기 전에 추가했다. 같은 200개 그래프에서 정상 신뢰도 값을 **같은 노드 유형 안에서** 무작위로 섞는다. 각 에피소드의 NumPy 난수 시드는 `episode_seed + 173`으로 고정한다. 이렇게 하면 노드와 신뢰도의 대응은 흐트러지지만 유형별 값의 분포와 그래프 전체 평균은 보존된다. 원천 오류와 전파·검토 난수도 원래 에피소드의 값을 사용한다.

먼저 같은 그래프에서 정상 신호와 섞은 신호에 대한 자동 판별 결과가 일치하는지 센다. 이어 섞은 신호에서 `adaptive_marginal`, 신뢰도를 버리고 공개 유형 사전확률에서 출발하는 `marginal`, 정상 모형으로 입력을 해석하는 고정 `observed` GNN의 잔여 결론 오류를 비교한다. 정책별로 정상 조건 대비 짝지은 변화량도 보고한다. 이 대조는 전체 평균이 변하지 않는 신호 손상을 자동 판별기가 감지할 수 있는지 확인하는 진단이다. 기존 판별 경계와 가중치를 고정하고 성능이 악화된 경우도 그대로 보고한다.

## 후속 진단 — 사람의 검토 결과로 신호 모형을 바꿀 수 있을까?

앞선 신뢰도 실험과 유형 내 섞기 대조 결과를 확인한 뒤, 다음 실험의 결과를 보기 전에 아래 비교를 정했다. 새 합성 그래프 **92000–92199** 총 200개를 사용한다. 같은 그래프에서 정상 신호, 독립 균등 잡음, 정상 점수를 유형 안에서 섞은 신호를 평가한다. 모두 검토 예산은 16회다. 기존 v3 `observed` GNN 세 체크포인트와 `marginal`의 점수 계산식을 그대로 사용한다.

각 점수 계산 방식에 대해 두 정책을 짝짓는다. 하나는 시작 시 그래프 평균으로 고른 신호 모형을 16회 내내 유지한다. 다른 하나는 매 검토에서 사람이 오류를 발견했는지에 따라 정상 모형과 유형 사전확률 모형 중 어느 쪽을 더 신뢰할지 갱신한다.

1. 시작 판별이 정상이면 정상 모형의 초기 확률을 0.8로, 그 외에는 0.2로 둔다. 매 선택 시 현재 확률이 더 큰 모형이 제공하는 상태로 노드의 점수를 계산한다.
2. 선택한 노드에서 각 모형이 추정하는 **발견 확률**은 공개 정보로 계산한 전파 포함 현재 오류확률에 0.9를 곱한 값이다. 각 확률을 `[1e-6, 1-1e-6]` 범위로 제한한다.
3. 사람이 오류를 발견하면 두 모형의 발견 확률 비율, 발견하지 못하면 미발견 확률 비율의 자연로그를 정상 모형의 로그 오즈에 더한다. 다음 선택부터 갱신한 값을 사용한다. 새 학습이나 추가 매개변수 탐색은 수행하지 않는다.

주 비교는 **유형 내 섞기 조건에서 검토 결과로 갱신하는 GNN의 최종 잔여 오류에서 시작 판별을 유지하는 동일 GNN의 오류를 뺀 값**이다. 같은 학습 시드와 그래프의 두 결과를 짝지어 그 차이를 계산하고, 시드와 그래프를 각각 재표집해 95% 교차 부트스트랩 구간을 구한다. 정상·균등 잡음 조건의 차이, 같은 비교를 적용한 `marginal`의 결과와 모형 전환 횟수는 보조 지표다. 효과가 어느 방향인지와 불확실성을 보고하며, 결론의 범위는 이 합성 그래프에서 고정 정책을 비교한 개발 실험까지다.
