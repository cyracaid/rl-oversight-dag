# 사전 등록: 범위(scope) 2층 혼합 실험

작성 2026-11-24, **실행 전**에 고정한다. 아래 정의·예측·판정 기준은 3600–3799 결과를 본 뒤 바꾸지 않는다.
바꿔야 하면 새 파일(`PREREGISTER_SCOPE_V2.md`)을 만들고 이 파일은 그대로 둔다.

## 왜 하는가

`shrink-v1`(seeds 3400–3599)은 사전 등록 판정에서 **성공**했지만, 예측에 넣지 않은 회귀가 하나 남았다.
무해한 전체 상향 이동(uniform 100 %·+3)에서 shrink 는 trust 보다 **+0.72** 나쁘고, 진짜 오류 노드의
평균 순위가 5.6 → 9.4 로 밀린다. 원인은 모형의 **범위**가 아니라 **층**이다.

`shrink` 는 노드마다 독립으로 "이 점수가 이동됐는가"를 묻는다. 전체가 +3 이동하면 각 노드 입장에서는
"나만 +3 이동했다"와 "전부 +3 이동했다"가 점수만으로 구별되지 않으므로, 높은 점수를 "깨끗한 노드가
위로 이동했다"로 읽고 오류 노드의 사후확률을 낮춘다. 반대로 `error_nodes` +3 처럼 일부만 이동하면
그 판단이 맞아서 이긴다(−0.370).

즉 남은 문제는 **이동의 크기가 아니라 범위**다. 이번에는 노드별 판단을 유지하되, 그 위에
"이 그래프 전체가 같은 δ 만큼 이동했는가"를 명시적 가설로 올린다.

## 정책 `scope` (동결)

관측 가능한 것만 쓴다: 공개 점수 `c`, 노드 타입과 타입별 사전확률 `r_i`, 간선·그래프 구조.
정답(`source_errors`), 간선 동전, 검토자 난수는 쓰지 않는다. 정책 규칙·예산 16회는 `trust`/`shrink` 와
동일하고, 입력 사후확률만 바뀐다.

환경의 공개 상수를 그대로 쓴다(`dag_role3/environment.py: initial_belief`).

```
z_i = logit(c_i)
bias_i = -0.4 * (r_i - 0.15)
정상 노드 i의 점수: z_i | b_i, δ_i ~ N(mu_b + bias_i + δ_i, SIGMA)
mu_1 = -1.5, mu_0 = +1.5, SIGMA = 1.2
δ 격자 Δ = {±0.5, ±1.0, ..., ±4.0}  (16개, 균등 가중)
노드별 이동 확률 π = 0.15   (shrink-v1 에서 확정된 값. 재적합하지 않는다)
```

노드별 주변우도(상태를 적분):

```
L_i(δ) = r_i φ((z_i - mu_1 - bias_i - δ)/SIGMA)
       + (1-r_i) φ((z_i - mu_0 - bias_i - δ)/SIGMA)
```

세 가지 범위 가설과 사전확률:

```
H0 (이동 없음)        사전 1 - p_g - p_s        우도 Π_i L_i(0)
H1(δ) (전체가 δ)      사전 p_g / |Δ|            우도 Π_i L_i(δ)
H2 (부분집합 이동)     사전 p_s                  우도 Π_i [ (1-π) L_i(0) + π·mean_δ L_i(δ) ]
```

사후 가중 `w_h ∝ 사전_h · 우도_h`, 노드 사후확률은 가설별 사후확률의 가중평균:

```
q_i = Σ_h w_h · P(b_i = 1 | data, h)
P(b=1 | h) = r_i φ_1 / [ r_i φ_1 + (1-r_i) φ_0 ]   (해당 h 의 δ 로 계산)
```

`q_i` 를 `_belief_base` 로 넣고 나머지는 `trust` 와 완전히 같다.

핵심 성질(설계 의도, 검증 대상): `H1(δ)` 의 우도는 80개 노드가 **같은 δ** 를 지지할 때만 커진다.
따라서 전체 이동에서는 `H1` 이 이기고 `q_i` 는 δ 를 되돌린 값, 즉 깨끗한 후보확률과 같아진다
(정책은 trust 처럼 행동). 부분 이동에서는 `H1` 이 80개 중 60여 개를 설명하지 못해 `H2` 가 이기고
`shrink` 와 같아진다. 이 실험은 **그 가설 선택이 실제로 맞는지**를 재는 것이지, 새 임계값을 찾는 것이 아니다.

## (p_g, p_s) 적합 (동결)

- 보정 그래프: **70000–70029** (30개), 에피소드 시드 `graph_seed + 20000`.
- 격자: `p_g ∈ {0.05, 0.10, 0.20, 0.35, 0.50}`, `p_s ∈ {0.20, 0.40, 0.60, 0.80}`, `p_g + p_s ≤ 0.95` 인 조합만.
- 각 조합에 대해 (a) 깨끗한 셀 평균, (b) 손상 격자 112셀 평균 잔여 오류를 계산한다.
- **허용 집합** = `clean_mean − clean_mean(trust) ≤ 0.05` 인 조합, 그리고 항상 `p_g = 0` 을 포함
  (`p_g = 0` 은 곧 `shrink` 이므로 기준선이 사라지지 않는다).
- 허용 집합 안에서 **손상 격자 평균이 최소**인 조합을 고른다. 동률이면 `p_g + p_s` 가 작은 쪽.
- 한 번만 적합하고 3600–3799 에는 재적합하지 않는다.

## 예측 (실행 전)

1. **회귀를 없앤다**: uniform 100 %·+3 에서 `scope − trust ≤ +0.20` (shrink 는 +0.72),
   그리고 uniform 100 %·+2 에서도 `≤ +0.20` (shrink 는 +0.45).
2. **은폐형 이득을 유지한다**: error_nodes 100 %·+3 에서 `scope − trust ≤ −0.30` (shrink 는 −0.370).
3. **깨끗한 비용이 작다**: 깨끗한 셀에서 `scope − trust ≤ +0.05`.
4. **전체로도 손해가 아니다**: 112셀 평균 `scope ≤ shrink`.
5. **부분 손상의 이득을 깨지 않는다**: uniform 50 %·−3 과 25 %·−3 에서 `scope − shrink ≤ +0.10`.

## 미리 적는 예상 손실 (실행 전)

`H1` 이 이기는 셀에서는 δ 를 되돌리므로 정책이 **trust 쪽으로 돌아간다**. 따라서
uniform 100 %·−4(shrink −0.88)와 −3(−0.66)의 이득은 사라질 것으로 **예상한다**. 그 이득은
"전체 이동을 인지하지 못해 생긴 착시"였고, 순위를 보존하는 전체 이동에서 옳은 행동은 되돌리기 때문이다.
이 손실은 예측 4(전체 평균)가 흡수하는지 여부로만 판정한다. 사후에 "역시 손해였다"고 말하지 않기 위해
지금 적는다.

## 한계 (미리 적음)

- δ 격자가 평가 격자의 이동 범위와 같다. 모형 선택의 순환 위험이 있고, 다른 손상 생성기
  (곱셈적 왜곡, 구간별 다른 δ, 노드별 임의 δ)에는 그대로 전이되지 않는다.
- `π = 0.15` 는 `shrink-v1` 에서 확정된 값을 물려받았다. 같은 보정 블록(70000–70029)이므로
  평가 시드 누출은 없지만, 이 실험이 π 를 독립적으로 검증하지는 않는다.
- `p_g`, `p_s` 는 80개 노드의 우도비가 워낙 커서 적합 곡선이 평평할 것으로 예상한다. 평평하면
  "사전확률은 거의 중요하지 않고 우도가 가설을 정한다"는 뜻이며, 그것도 결과로 보고한다.
- 정규분포·등분산·노드 독립 가정은 이 합성 Spike 생성기의 것이다. 실제 손상은 locality 단위
  (all-or-none)라 노드 독립 가정은 증거를 과소평가하는 보수적 방향이다.
- `oracle` 은 정답을 쓰므로 비배포. 단일 marginal 규칙, 단일 그래프 family, 학습 정책 없음.
