# 유형별 점수 갱신의 독립 확인 조건

부분 손상 실험을 읽기 전에 후보와 평가 조건을 고정한다. 1–4개 유형 손상 중 어느 조건에서든 전체 그래프를 한꺼번에 갱신한 규칙이 고정 규칙 하나보다 많은 오류를 남기고, 해당 짝지은 차이의 95% 구간 하한이 0보다 크면 다음 실험을 실행한다. 이 발동 기준은 탐색적이다. 독립 확인은 새 그래프에서 한 조건만 평가한다.

- 평가 그래프는 97000–97199, 손상 유형은 2개, 난수 공유와 손상 생성은 본 실험과 같다. 그래프당 검토는 16회다.
- 후보는 하나다. 기존 피드백 규칙과 같은 두 모형으로 직전 검토 결과의 우도비를 계산한다. 검토한 노드 유형에 그 로그 우도비를 누적하고, 전체 그래프에도 같은 증거를 한 번 누적한다. 유형별 검토 횟수가 (n)이면 유형별 누적 증거와 그래프 전체 누적 증거의 가중치는 각각 `n/(n+2)`와 `2/(n+2)`다. 두 번 검토한 유형에서 두 가중치가 같아지도록 상수 2를 고정했다. 이 계산은 증거를 빌려 쓰는 근사 규칙이다.
- 공개 점수 평균에서 구한 기존 사전 로그 오즈에 위 가중 평균을 더한다. 결과가 0 이상인 유형은 점수를 신뢰한 원천 오류 확률을, 나머지는 점수를 무시한 원천 오류 확률을 쓴다. 이 혼합 원천 확률로 전체 그래프의 하류 영향 점수를 다시 계산해 다음 항목을 고른다. 검토할 때마다 반복한다. 유형별 검토 횟수·관측만 추가로 보며 손상 유형과 정답은 제공하지 않는다.
- 주 비교는 후보에서 기존 전체 그래프 갱신 규칙을 뺀 최종 결론 오류다. 그래프 단위 10,000회 짝지은 재표집 95% 구간의 상한이 0 미만이면 후보의 개선으로 판정한다. 점수 항상 신뢰 및 항상 무시와의 차이는 보조 비교로 함께 보고한다. 앞선 개발 결과를 보고 후보, 조건, 시드 또는 기준을 다시 고르지 않는다.
