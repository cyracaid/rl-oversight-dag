# 일부 유형에서 점수가 뒤섞인 경우의 검토 정책 비교

실행 전에 조건을 고정했다. 주 비교는 [후속 실험 계획](후속실험계획.md)의 1번이다.

- Spike 그래프 95000–95199에서 80개 항목 중 16개를 검토한다. 결론 20개 중 잘못된 채 남은 개수가 주 지표다. 각 그래프에서 6개 손상 조건과 3개 정책에 같은 숨은 원천 오류, 전파 여부, 항목별 검토 난수를 쓴다.
- 그래프 다섯 개를 한 묶음으로 둔다. 묶음의 첫 그래프 시드에 420001을 더해 유형 5개의 순서를 무작위로 정한 뒤 그래프마다 한 칸씩 순환시킨다. 앞에서부터 0–5개 유형을 선택하므로 해당 개수에서 각 유형을 같은 횟수만큼 손상한다. 그래프별로 기존 전체 순열을 한 번 만들고, 선택한 유형의 값만 바꾼다. 우연히 제자리에 남는 점수도 있어 실제 바뀐 항목 비율을 별도로 잰다.
- 점수를 항상 믿는 정책, 항상 무시하는 정책, 그래프 전체에서 발견·미발견에 따라 둘 중 하나를 고르는 기존 정책을 비교한다. 세 정책 모두 다음에 볼 항목은 같은 하류 영향 규칙으로 고른다. 갱신 정책의 초기 확률과 갱신식은 이전 실험과 같다. 정책에 섞은 유형이나 개수를 알려주지 않는다.
- 주 조건은 2개 유형 손상이다. 갱신에서 각 고정 정책을 뺀 차이의 개별 95% 구간이 둘 다 0 아래에 있을 때 두 정책보다 개선됐다고 판정한다. 그래프를 짝지어 10,000회 재표집한다. 나머지 조건과 순위 교차 범위는 탐색 결과로 보고한다.
- 손상 0개와 5개의 입력이 기존 정상·전체 순열 입력과 동일한지 확인한다. 각 그래프의 여섯 조건에서 점수를 항상 무시할 때의 선택 순서와 잔여 오류가 같은지도 확인한다. 검토 횟수와 초기 오류를 모두 대조한다.

후속 후보는 일부 손상 조건(1–4개)에서 전체 갱신의 잔여 오류가 적어도 하나의 고정 정책보다 많고 짝지은 차이의 95% 구간이 0보다 클 때 검토한다. 이 기준은 탐색 결과를 다음 독립 비교로 넘기기 위한 선택 규칙이다. 새 후보를 평가한다면 97000–97199의 결과를 보기 전에 조건과 후보를 별도로 고정한다.
