## 2. 그녀가 할 것 — 순서대로

### ① 같은 층 안의 두 δ (씨드 5000–5099)

지금까지 경계 실험은 **서로 다른 두 층**을 각각 다른 δ로 밀었다. 같은 층 안에서 두 δ가
섞이는 경우는 아직 재본 적이 없다. scope 모델의 마지막 구멍이다. 100장, 20칸, 경계 실험과 같은 비용.
**PREREGISTER 먼저 커밋**, 그 다음 실행. 예상은 "단일 δ는 하나를 포기하고 신뢰 수준으로 돌아간다"지만,
예측이 틀리면 `contradicted`로 남긴다 — `scope-robust-v1`과 같은 형식.

### ② `p_catch` × `scope` 교차

적중률 0.60에서 δ가 여전히 추정되는가. 두 계열이 만나는 유일한 지점이고, 여기서 무너지면
그게 두 번째 경계 측정이 된다.

### ③ Gap D 데이터 요청 → 도착하면 실행

`DATA_REQUEST_GAP_D.md`의 열(column) 그대로 요청한다. 핵심 함정 하나:
**수정된 75건만 내보내면 음성 표본이 없어서 보정이 불가능하다.** 무작위 표본 + 플래그된 노드를 함께,
표집 규칙을 manifest에 적는다. 최소 200행, 30레코드, 두 클래스 각 20개 이상.

```bash
python3 signal_calibration_real.py --csv audit_nodes.csv --human-audited \
    --out results/calibration-v1
```

AUC가 0.5 근처로 나오면 그건 실패가 아니라 **가장 중요한 발견**이다. 그때는 신뢰도 신호 계열
전체가 시뮬레이터 밖에서 무효라는 뜻이므로, 그대로 보고한다.

### (선택) 보상 배분의 "학습은 되는데 배포는 안 된다" 진단

4.549 → 2.926(5/5 시드)은 학습 결과로는 진짜다. 배포 비교는 2.945 vs 2.765로 진다.
이 비대칭 자체가 논문 한 문단이 될 수 있지만, 지금은 숫자 하나뿐이라 **메커니즘 실험을 설계한 뒤**에 쓴다.

## 4. 규칙 세 줄

1. PREREGISTER 커밋 → 실행 → 판정 코드가 CSV에서 계산.
2. 결과 폴더마다 `manifest.json`(시드·예산·sha256).
3. 영(null)은 "효과 없음"이 아니라 **"not supported"**로 쓴다.
