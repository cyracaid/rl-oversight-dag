### 점수가 통째로 어긋났을 때 · 게이트 → 노드 → 그래프 → 경계

앞의 실험은 점수가 **일부만** 어긋난 경우였다. 실제 파이프라인에서는 점수 전체가 한 방향으로 밀린다. 이때 “믿을까/버릴까”를 고르는 이진 판단은 두 방향으로 틀린다. 그래서 질문을 **“어느 신호를 믿을지 추정하고, 믿을 수 없으면 안전하게 행동하기”**로 바꿨다. 다섯 단계 모두 실행 전에 규칙과 판정을 동결했고, 단계마다 새 그래프 구간을 썼다. [단계별 전체 지도](실험통합정리.md#3-1-신뢰도-손상-이후--게이트--노드--그래프--경계) · [개선 과정](개선과정.md#4차-이후--점수를-믿을-수-없을-때-무엇을-할-것인가로-질문을-바꿨다)

| 단계 | 정책 | 물은 질문 | 새 그래프 | 동결 판정 | 결과 |
|---|---|---|---|---|---|
| ① 전역 게이트 | `gate` | 점수 전체가 오염됐는가? | 3000–3199 | 경계 측정 | 무해한 −1에 195/200 발동(**+1.82** 손해), 가리는 +3은 0/200(**+3.21** 손해) |
| ② 게이트 수정 | `verify` | 오염됐다면 순위를 복원할 수 있는가? | 3200–3399 | **실패** | −1 손실은 사라졌지만 13칸 중 5칸이 신뢰보다 나쁨 |
| ③ 노드별 | `shrink` | 어느 노드가 움직였는가? | 3400–3599 | 성공 | −1에서 **+0.105**, 가리는 +3에서 **−0.370** (첫 역전), 전체 상향 +0.45/+0.72 손실 |
| ④ 그래프별 | `scope` | 그래프 전체가 움직였는가, 얼마나? | 3600–3799 | 성공 | +3에서 **+0.005**(③은 +0.81), 112칸 평균 1.303 → **1.203**, 가리는 이동에서 +0.325 되돌려줌 |
| ⑤ 경계 | `scope` | ④는 자기 가정 밖에서 어디까지 버티는가? | 3800–3899 | **부분 성공** | 격자 밖 δ는 버팀(오차 0.174, 12칸 전부 ③보다 좋음), 두 δ는 **동률**(−0.016) |

가장 중요한 문장은 ⑤다. 두 층이 서로 다른 δ로 동시에 움직이면 단일 δ 모형은 하나를 포기하고, 노드별 방식도 같은 조건에서 신뢰 수준으로 돌아간다(신뢰 2.15 / 노드별 1.89 / 그래프별 1.87). 즉 **“우리 방법이 이겼다”가 아니라 “이 조건에서는 어떤 단일 δ 방법도 회복하지 못한다”**가 측정된 사실이다. 사전에 적은 “두 δ에서 ③이 더 낫다”는 예측은 철회했다.

모든 실행은 검토 적중률 90 %를 가정했다. 60·75·90·100 %로 다시 돌린 결과 규칙 우위의 **방향**은 네 칸 모두 유지됐고(+0.255 / +0.350 / +0.415 / +0.530), “적중률이 낮을수록 격차가 커진다”는 예측만 반대로 나왔다. [적중률 스윕](../PREREGISTER_P_CATCH.md)

### 발견·미발견 뒤의 다음 검토까지 계획한 결과

이번에는 신경망 학습 없이 하류 영향이 큰 6개 노드를 첫 검토 후보로 두고, 각 후보에서 오류가 발견됐을 때와 발견되지 않았을 때 두 번째로 검토할 노드를 계산했다. 공개 신뢰도를 얼마나 믿을지도 검토 결과로 갱신했다. 새 Spike 그래프 200개(94000–94199)에서 기존 1단계 규칙, 두 신호 모형을 혼합한 1단계, 같은 후속 노드를 가정한 2단계, 결과별로 후속 노드를 고르는 2단계를 동일한 검토 예산 16회로 비교했다. [정책 정의와 사전 비교 설계](두단계계획.md)

주 비교인 유형 내 신뢰도 순열에서 그래프당 남은 결론 오류는 혼합 1단계 **3.075개**, 결과별 2단계 **3.110개**였다. 차이는 **+0.035개**(짝지은 95% 구간 −0.025~+0.100)였다. 결과별 2단계가 더 적은 오류를 남긴 그래프는 5개, 동률은 183개, 더 많은 오류를 남긴 그래프는 12개였다. 첫 15번의 검토 중 가상 발견·미발견에 따라 다음 후보가 갈린 비율은 38.2%였고, 현재 선택도 혼합 1단계와 18.8% 달랐다. 이 예산과 그래프에서는 선택 순서가 달라져도 두 단계 계획의 최종 오류 감소를 확인하기 어려웠다. [결과와 실제 선택 사례](results/planning-v1/planning.md) · [그래프별 원자료](results/planning-v1/episodes.csv)

### 하류 영향 규칙에서 출발해 검토 순위를 학습한 결과

`residual` GNN은 각 노드의 하류 영향 점수에 학습된 보정값을 더한다. `feature_only` GNN은 같은 점수를 입력으로 받고 자체 출력으로 순위를 정한다. 두 모델을 같은 사례와 학습 시드 5개로 각각 384에피소드 학습하고, 검증에서 선택한 모델을 별도 그래프 200개(93000–93199)에서 평가했다. 검토 예산은 16회로 고정했다. [사전 비교 설계](잔차학습계획.md)

주 비교인 유형 내 점수 순열에서 그래프당 남은 결론 오류는 `feature_only` **4.543개**, `residual` **2.682개**, 기존 하류 영향 규칙 **2.660개**였다. 직접 보정하는 구조는 특징 전용 GNN보다 오류를 1.861개 줄였다(짝지은 95% 구간 1.170–2.448개 감소). 규칙과의 차이는 **+0.022개 [−0.018, +0.072]**여서 학습 보정의 추가 이득은 확인하기 어려웠다. 이 조건에서 보정이 규칙과 다른 노드를 고른 비율은 8.9%였고, 시드 5개 중 1개는 검증에서 보정값이 0인 초기 정책을 선택했다. 동일한 16회 검토를 쓰는 현재 합성 환경에서는 기존 하류 영향 규칙을 기본 정책으로 유지할 근거가 된다. [결과와 시드별 차이](results/residual-v1/residual.md) · [실제 선택이 갈린 사례](results/residual-v1/decision.md) · [효과 그림](results/residual-v1/residual_effect.png)

### 신뢰도 모형 선택과 기준선

첫 평가에는 3번의 `observed` GNN + REINFORCE 체크포인트 3개를 사용했다. 각 모델은 1,000에피소드 학습 중 별도 검증 그래프로 선택했다. 아래 값은 같은 200개 그래프에서 검토 후 남은 **그래프당 평균 결론 오류**다. [시드별 비교와 95% 구간](results/confidence-v1/comparison.md) · [점수 재배정 대조](results/confidence-v1/shuffle_control.md)

| 정책 | 정상 점수 | 균등 잡음을 정상으로 해석 | 유형 안에서 정상 점수를 섞음 |
|---|---:|---:|---:|
| 기존 학습 GNN, 시드 3개 평균 | 1.485 | 4.857 | 4.342 |
| 점수·하류 영향으로 선택하는 `marginal` | 1.130 | 4.415 | 4.085 |
| 그래프 평균 점수로 신호 모형을 고르는 `adaptive_marginal` | 1.130 | 3.150 | 4.085 |

정상 조건에서 GNN은 검토한 노드의 44.1%에서 오류를 발견했고 `marginal`은 36.2%에서 발견했다. 한 번의 검토로 줄인 **결론 오류**는 각각 0.289개와 0.311개였다. 어느 노드를 고치느냐에 따라 오류 하나를 발견했을 때의 하류 효과가 달랐다. 점수 분포가 달라지는 균등 잡음에서는 자동 보정이 그래프당 1.265개를 줄였다. 유형 안에서 점수만 섞자 모든 그래프의 평균이 유지되어 보정 규칙이 손상을 놓쳤다. [그래프별 측정값](results/confidence-v1/episodes.csv)

### 검토 피드백으로 보정한 후속 실험

겉으로 정상처럼 보이는 손상을 알아차리기 위해 매 검토의 발견·미발견 결과를 두 신호 모형의 예측과 대조했다. 직전 검토까지 관측한 정보로 다음 행동에 사용할 오류확률 추정을 갱신했다. 모델 가중치와 검토 예산을 고정하고 **별도 그래프 200개**에서 검증했다.

같은 유형 안에서 점수를 섞은 주 비교에서 GNN의 잔여 오류는 **4.083개에서 3.853개**로 줄었다. 그래프당 감소량은 **0.230개**였고 짝지은 95% 구간은 **0.112–0.340개**였다. 정상 신호와 균등 잡음에서는 GNN 개선을 확인하기 어려웠다. 같은 피드백을 쓴 하류 영향 규칙은 순열 조건에서 **3.075개**를 남겨 GNN보다 적었다. 이번 결과는 신호가 손상됐을 때 관측을 갱신하는 방법이 도움이 될 수 있음을 보여준다. 적용 범위는 모의 검토자와 합성 Spike 그래프, 고정된 GNN 학습 시드 3개다. ## 실행

두 단계 검토 계획을 재현하려면 저장소 루트에서 아래 명령을 실행한다. 모델 학습 없이 그래프 200개를 평가한 뒤 실행 폴더에 `planning.md`, `episodes.csv`, `trace.csv`, `manifest.json`을 저장한다. `--jobs`는 동시에 평가할 그래프 작업자 수다.

```powershell
python -X utf8 '.\role2_규리\run_experiment.py' --profile planning --jobs 5
```

저장소 루트에서 PowerShell로 실행한다. 의존성은 `python -m pip install -r '.\role3 improvement\requirements.txt'`로 설치한다. 저장된 모델로 평가를 재현하는 명령은 다음 두 가지다.

```powershell
python -X utf8 '.\role2_규리\run_experiment.py' --profile assess
python -X utf8 '.\role2_규리\run_experiment.py' --profile feedback
```

`assess`는 그래프 91000–91199에서 세 신뢰도 조건과 유형 내 섞기 대조를 실행한다. `feedback`은 별도의 그래프 92000–92199에서 검토자의 발견·미발견에 따라 신호 모형을 갱신할 때의 효과를 측정한다. 두 평가 모두 점수 보정용 그래프 70000–70099와 구간이 겹치지 않는다.

새 모델을 학습하는 경로도 제공한다.

하류 영향 점수를 직접 보정하는 후속 학습과 대조 실험은 아래 명령으로 재현한다. 학습 시드 5개에 대해 각각 두 GNN을 학습한 뒤 검증에서 선택한 정책을 새 그래프 200개에서 비교한다. `--jobs`는 동시에 학습할 시드 수이며 기본값은 1이다. `train/seed-*/`에는 체크포인트와 학습·검증 기록이, `eval/`에는 그래프별 측정값이, `residual.md`에는 시드별 선택과 비교 결과가 저장된다. [잔차 학습 설계](잔차학습계획.md)

```powershell
python -X utf8 '.\role2_규리\run_experiment.py' --profile residual --jobs 5
```

```powershell
python '.\role2_규리\run_experiment.py' --profile full
```

`full`은 두 모델을 각각 학습 시드 1–5에서 20,000에피소드씩 학습한다. 검증 그래프 30개로 체크포인트를 고르고, 기본 벤치마크(90000–90199), 신뢰도 조건 실험, 검토 피드백 실험 순서로 평가한다. 입력에 검토 이력이 있는 `observed` 모델이 피드백 실험에 참여한다. 이 구간들은 개발 비교에 사용한 그래프다. 전체 학습은 CPU에서 오래 걸릴 수 있다.

## 결과

실행 폴더는 기본적으로 `role2_규리/runs/` 아래에 프로필과 실행 시각으로 생성된다. `--out`에 새 폴더 경로를 지정할 수 있다. 상대 경로는 명령을 실행한 위치부터 계산한다. 실행 시 결과 경로가 출력된다.

- `smoke`와 `full`은 `config.json`에 학습 설정을 저장한다.
- `train/<variant>/seed-<n>/`에 체크포인트와 학습·검증 CSV를 저장한다.
- `eval/`에 정책별 에피소드 결과 CSV, 요약 CSV, 그래프 PNG, 실행 매니페스트를 저장한다.
- 신뢰도 조건 결과는 `conditions/comparison.md`와 `conditions/shuffle_control.md`, 검토 피드백 결과는 `feedback/feedback.md`에 저장한다. `assess`와 `feedback` 프로필은 해당 보고서를 실행 폴더 바로 아래에 저장한다. 보고서 옆의 `episodes.csv`와 `manifest.json`에 짝지은 원자료와 재현용 해시가 있다.

요약의 `gain_vs_confidence`는 신뢰도순 기준선의 잔여 오류에서 해당 정책의 잔여 오류를 뺀 값이다. 양수면 해당 정책의 오류가 더 적다. `paired_lo`와 `paired_hi`는 한 모델의 짝지은 평가 그래프를 재표집한 95% 구간이다. v3의 `marginal`은 평균장 근사 기준선이다. 이전 발표의 `belief greedy`와 `2-step greedy`는 별도 경계 실험에 정의되어 있다. [이전 경계 실험](../experiments/BOUNDARY_RUN.md)
