# 교수 피드백을 반영한 Role 2 발표 구성안

2026년 11월 23일 강화학습 팀 발표 녹음을 정리한 팀 기록을 바탕으로, 기존 14장 발표본의 3–10장에 넣을 내용을 정리했다. **한 가지 수면 사례로 오류와 전이를 설명하고, 교수님이 가장 강조한 세 요소의 대응표를 먼저 보여준다.** 이어서 같은 검토 예산에서 규칙과 GNN을 비교한 결과, 신뢰도 보정이 도움이 된 조건과 새로 확인한 경계를 연결한다. [교수 피드백 기록](../RL_연구요점_교수피드백_KO.md#1-교수-피드백-항목별) · [기존 14장 발표 원고](../presentation_20261116/Speaker_Script_Wed.md)

## 교수 피드백과 반영 위치

| 교수님이 물으신 내용 | 화면에 넣을 답 | 기존 발표본 위치 |
|---|---|---|
| 무엇을 오류라고 부르는가 | 사람이 확인하고 고칠 수 있는 파이프라인 출력값의 오류. 시간 순서 오류, 잘못 계산된 간격, 범위를 벗어난 지표 | 3장 |
| 각 단계에서 무엇이 나오고 무엇이 틀릴 수 있는가 | 수면 DAG의 수집·전처리·분석·결론별 출력과 오류 예시. 교정 기록의 구성비와 모의실험에 넣은 오류 확률 | 4장, 14장 |
| 분석·결론도 틀리는가. 숨은 오류, 상태, 전이는 무엇인가 | 노드 자체의 원천 오류와 상류에서 전파된 오류를 구분. 정책이 보는 정보와 한 번 검토한 뒤 달라지는 값 표시 | 4장, 6장 |
| 세 요소를 왜 함께 다뤄야 하는가 | 검토가 한 번 남았을 때 오류가 의심되는 말단 항목과 여러 결론에 영향을 주는 상류 항목 중 무엇을 고를지 보여주기 | 5장 |
| 사람 검토·예산·오류 전파가 방법론에 어떻게 들어가는가 | 검토할 노드 선택, 남은 횟수와 종료 조건, 정정 후 하류 재계산과 최종 오류 수의 세 줄 대응표 | 5장 |
| 학술 용어로 어떻게 표현하는가 | 불확실한 판단의 전문가 검토 위임(`learning to defer`), 검토 예산(`review budget`), 하류 오류 전파(`error propagation`) | 5장, 6장 |

교수님은 단계별 설명에 MNIST 이미지 분류를 예로 들었다. 발표에서는 교정 사례와 DAG가 이미 있는 수면 파이프라인 하나로 3–6장을 이어 가면 된다. [피드백 대응 슬라이드 초안](../presentation_20261116/Feedback_Patch_EN.md)

## 본문 슬라이드에 넣을 내용

기존 5분 발표를 기준으로 3–10장에 약 3분 30초를 배정했다. 각 장의 번호는 기존 14장 발표본 기준이다.

### 3장 출력값 오류의 예시 25초

**화면.** 제목은 ‘어떤 값을 검토하는가’. 한 줄 정의 아래에 **시간 순서 오류**(기상 시각이 입면보다 앞섬), **파생값 오류**(기상부터 침대에서 나오기까지의 간격이 잘못 계산됨), **지표 오류**(수면 효율이 100%를 넘음)를 놓는다. 이 실험에서 사람의 검토 대상은 개별 출력값이다. 수치는 **“실제 교정 75건 중 57건(76%)이 시간 순서 오류”**만 크게 쓴다.

**발표 멘트.** “사람이 확인하는 것은 자동으로 기록되거나 계산된 값입니다. 예를 들어 기상 시각이 입면 시각보다 앞선 행이 들어올 수 있습니다. 실제 교정 75건 중 57건이 시간 순서 오류였습니다.” [오류 유형과 분모](../presentation_20261116/Feedback_Patch_EN.md#appendix-table--full-error-breakdown-keep-off-the-main-path)

### 4장 수면 DAG에서 오류가 이동하는 경로 30초

**화면.** 21노드 수면 DAG에서 수집·전처리·분석·결론 네 층과 결론 노드 4개를 표시한다. 그중 **야간 각성 시간 자기보고(`waso_self`) → 각성 시간 계산(`WASO_calc`) → 총수면시간(`TST`) → 수면 효율(`SE`) → 수면 효율 판정(`SE_conclusion`)**을 색으로 연결한다. 총수면시간과 수면 효율은 둘 다 분석층에 놓는다. 단계별 오류 예시는 자기보고 값 오기, 각성 시간 계산 오류, 비정상 수면 효율, 잘못된 품질 판정으로 한 줄씩 표시한다. 네 층별 실측 오류율을 제시하려면 발생 단계가 기록된 검증 자료가 필요하다. 현재 교정 비중과 시뮬레이션의 유형별 사전확률은 14장에서 출처와 분모를 밝혀 제시한다.

**발표 멘트.** “노드 하나는 각 단계가 만든 출력값 하나입니다. 밤중에 깨어 있던 시간을 잘못 기록하면 그 값으로 계산한 총수면시간과 수면 효율, 최종 판정까지 달라질 수 있습니다. 분석 지표나 최종 판정도 자체 오류를 가질 수 있습니다.” [수면 DAG 그림](../experiments/sleep_dag_4stage.png) · [네 층과 의존성 정의](../role3%20improvement/dag_role3/graphs.py)

### 5장 세 연구 요소와 방법의 대응 35초

**화면.** 위쪽에 ‘검토 한 번이 남았을 때 어느 값을 볼까?’를 쓰고, 수면 경로를 작게 재사용한다. 아래쪽에 다음 표를 둔다.

| 연구 요소 | 방법에서 구현한 부분 |
|---|---|
| 불확실한 판단의 전문가 검토 위임 | 아직 검토하지 않은 노드 하나를 행동으로 선택. Role 2 기본 설정에서 자체 오류가 있는 노드를 검토하면 발견·정정 확률 0.90 |
| 한정된 검토 예산 배분 | 상태에 남은 횟수를 포함. 검토하면 한 번 차감하고 모두 쓰면 종료 |
| 하류 오류 전파 | DAG 의존성을 따라 정정 결과를 다시 계산. 마지막에는 결론 노드에 남은 오류 수를 세고, 학습의 종료 보상은 그 수에 마이너스를 붙임 |

**발표 멘트.** “검토가 한 번 남았으면 오류가 의심되는 값과 고쳤을 때 여러 결론에 영향을 줄 값 중에서 골라야 합니다. 사람 검토는 행동을 정하고, 예산은 언제 끝나는지 정합니다. DAG는 한 값을 고쳤을 때 어떤 결론이 달라지는지 정합니다.” [교수님의 방법론 매핑 요청](../RL_연구요점_교수피드백_KO.md#15-세-요소--방법론-매핑-교수-최대-강조) · [Role 2 실험에서 구현한 항목](실험계획.md)

### 6장 검토 한 번에 상태가 바뀌는 방식 25초

**화면.** **관측 → 노드 선택 → 발견 또는 미발견 → 확인한 결과와 남은 예산 갱신**의 네 칸을 그린다. 관측에는 노드 유형·신뢰도·구조·검토 이력·오류 확률 추정치·남은 횟수를 놓는다. 노드 자체의 실제 오류 여부는 숨은 상태로 표시한다. 오류를 발견하면 선택 노드의 자체 오류를 고치고 하류를 다시 계산한다. 상류 원인이 남아 있으면 물려받은 오류가 남을 수 있다.

**발표 멘트.** “정책은 어느 노드가 정말 틀렸는지 모르는 상태에서 한 곳을 고릅니다. 검토자가 야간 각성 시간 기록의 오류를 발견해 고치면 각성 시간 계산과 총수면시간, 수면 효율과 판정을 다시 계산합니다. 남은 검토 횟수는 발견 여부와 관계없이 하나 줄어듭니다.” [벤치마크의 관측과 전이 정의](../BENCHMARK_SPEC.md#1-task) · [원천 오류와 전파 오류](../experiments/SEMANTICS_AUDIT.md)

### 7장 벤치마크와 비교 기준 20초

**화면.** **합성 Spike 80노드 → 서로 다른 노드 16곳 검토 → 결론 20개에 남은 오류 수**를 한 줄로 표시한다. 이 주 지표는 그래프당 평균이며 낮을수록 좋다. 같은 실행 안에서 각 정책은 동일한 그래프·초기 오류·전파·검토 난수를 공유한다. `confidence`는 낮은 신뢰도순, `marginal`은 한 번 고쳤을 때 줄일 것으로 기대되는 결론 오류가 가장 큰 노드부터 선택한다. 수면 21노드 DAG는 문제를 설명하는 구조로 표시한다.

**발표 멘트.** “16곳을 보고 난 뒤 최종 결론 20개 중 몇 개가 여전히 틀리는지 셉니다. 같은 그래프에서 신뢰도순, 하류 영향 규칙, 학습 정책을 비교합니다.” [벤치마크 지표와 기준선](../BENCHMARK_SPEC.md#4-metric)

### 8장 강한 규칙과 강화학습 비교 25초

**화면.** 1,000에피소드 모델의 정상 신뢰도 확인 실험을 막대 3개로 보여준다. 신뢰도순 **1.275**, 하류 영향 규칙 **0.885**, GNN+REINFORCE **1.262**다. 막대 아래에 **GNN − 규칙 +0.377개 [95% 구간 +0.255, +0.510]**를 적는다. 같은 표의 발견율은 GNN **45.6%**, 규칙 **38.6%**였다. 발표 시간이 짧으면 발견율은 멘트 한 문장으로 처리한다.

**발표 멘트.** “이 200개 그래프에서 규칙이 가장 적은 결론 오류를 남겼습니다. GNN은 검토 중 오류를 더 자주 발견했지만 검토를 끝낸 뒤 남은 결론 오류도 더 많았습니다.” [정상 신뢰도 확인 결과](results/confirm-v1/comparison.md)

### 9장 신뢰도 보정이 필요해진 이유 25초

**화면.** 전역 게이트, 수정한 게이트, 그래프별 보정의 세 칸을 둔다. 첫 게이트는 순위를 보존하는 −1 이동을 **200개 중 195개**에서 손상으로 판정했다. `verify`도 작동한 13개 조건 중 **5개**에서 점수를 그대로 쓴 정책보다 오류를 더 남겼다. `scope`는 점수 이동이 영향을 준 노드의 비율과 공통 이동량을 추정해 초기 오류 확률을 보정한다. 전체 +3 이동에서 점수를 그대로 쓴 경우 대비 **+0.005개**였다. 노드별 `shrink`는 개별 노드의 점수가 이동했을 가능성을 반영하며, 은폐형 조건의 결과는 부록에서 함께 보여준다.

**발표 멘트.** “점수가 조금 이동했다고 전부 버리면 검토 결과가 나빠질 수 있었습니다. 점수가 얼마나 이동했는지를 반영해 검토를 시작하면, 전체 +3 이동에서는 점수를 그대로 쓴 경우에 가까웠습니다.” [전역 게이트](results/corruption-v1/corruption.md) · [게이트 수정](results/verify-v1/verify.md) · [그래프 단위 보정](results/scope-v1/scope.md)

### 10장 같은 층에 두 이동량이 있을 때 25초

**화면.** 위에 한 층을 두 색으로 나눈 그림을 놓고 두 집단에 서로 다른 이동량을 표시한다. 아래 표에는 **점수를 그대로 사용 1.7180 / 노드별 보정 1.6905 / 그래프별 보정 1.6690**을 넣는다. 각 값은 새 합성 그래프 100개, 혼합 20조건, 검토 16회에서의 평균이다. 바로 옆에 주 비교 **그래프별 − 노드별 −0.0215개 [짝지은 95% 구간 −0.0470, +0.0030]**를 넣는다.

**발표 멘트.** “이번에는 같은 층 안에서 두 집단의 점수를 서로 다르게 움직였습니다. 두 보정 방식 모두 점수를 그대로 썼을 때보다 평균 오류가 조금 적었습니다. 그래프별과 노드별 보정의 차이는 구간이 0을 포함했습니다.” [층 안 혼합 사전등록](PREREGISTER_SCOPE_WITHIN.md) · [새 실험 결과](results/scope-within-v1/report.md)

**시간이 남으면 덧붙일 한 문장.** “별도 민감도 실험에서 하류 영향 규칙이 60~100% 적중률 모두에서 신뢰도순을 앞섰고, 우위는 적중률이 높을수록 커져 사전 예측과 반대였습니다.” [적중률 민감도 결과](../role3%20improvement/outputs/p-catch-v1/report.md)

## 질의응답용 부록

기존 14장의 분모 설명은 유지하고, 다음 결과는 해당 질문이 나오면 별도 부록 표로 제시한다. 여러 실험의 평균은 그래프·조건이 달라서 한 막대그래프의 순위로 합치면 해석이 달라진다. 각 비교에 평가 조건과 짝지은 차이를 붙인다.

| 질의응답 주제 | 부록에 넣을 근거 |
|---|---|
| 76%가 수면 데이터 전체의 오류율인가 | 전체 추출 자료 교정 비율 **75/13,990 = 0.54%**, 자동 감사 표시 건의 오류 확인 비율 **68/1,048 = 6.5%**, 교정 중 시간 순서 오류 비중 **57/75 = 76%**. 유형별 시뮬레이션 사전확률에는 별도 표제를 붙인다. [발표본 14장 자료](../presentation_20261116/Feedback_Patch_EN.md#appendix-table--full-error-breakdown-keep-off-the-main-path) |

## 발표 직전 확인할 문장

- “구체적 오류가 무엇인가”에는 잘못 기록된 야간 각성 시간과, 이를 고치면 다시 계산하는 총수면시간·수면 효율·판정으로 답한다.
- “왜 세 요소가 필요한가”에는 남은 검토 한 번을 어디에 배정할지로 답한다. 바로 이어서 행동·종료 조건·전이와 보상을 보여준다.
- “실험으로 무엇을 확인했나”에는 정상 조건의 강한 규칙 우위와, 합성 손상 조건에서 보정 방식에 따라 달라진 잔여 오류를 각각 말한다. 새 실험의 주 비교는 신뢰구간까지 읽는다.
