# 범위 모형의 경계: 격자 밖 δ와 두 개의 δ

사전 등록(`PREREGISTER_SCOPE_ROBUST.md`) 후 새 그래프 100개(seed 3800–3899)에서 격자 밖 이동 12셀과 두 층 동시 이동 8셀을 쟀다. 예산 16회, `p0 = 0.20`, `π = 0.15`는 이전 실험의 적합값을 그대로 쓴다. 재적합 없음.

이 실험은 새 모형을 제안하지 않는다. 이미 확정된 모형의 **가정 두 개**를 하나씩 깬다. δ가 격자 위에 있다는 가정, δ가 하나라는 가정. 둘 다 생성기의 성질이지 실제 파이프라인의 성질이 아니다.

## 예측 대조와 판정

- 격자 밖 δ에서 최빈 셀이 이웃을 고른다 (평균 |δ_err|): **성립** (+0.174, 기준 <= +0.50).
- 격자 밖 100 % 셀에서 최빈 비율이 1이다 (평균 map_q): **성립** (+0.991, 기준 >= +0.95).
- 격자 밖 큰 음의 이동에서도 이득이 남는다 (평균 scope − trust): **성립** (-2.120, 기준 <= -0.50).
- 격자 밖 큰 양의 이동에서 손해가 없다 (평균 scope − trust): **성립** (-0.025, 기준 <= +0.20).
- 깨끗한 그래프 비용 (scope − trust): **성립** (+0.000, 기준 <= +0.05).
- 두 δ에서 shrink보다 나쁘다 (평균 scope − shrink): **불성립** (-0.016, 기준 > +0.00).
- 두 δ에서 전체 이동을 주장하지 않는다 (평균 map_q): **성립** (+0.169, 기준 <= +0.50).

사전 등록 판정: **부분 성공**.

격자 밖 강건성은 확인됐지만 두 δ 경계 예측 하나가 빗나갔다. 어느 쪽이 빗나갔는지가 모형이 생각보다 넓거나 좁다는 뜻이므로, 그 방향으로만 해석한다.

## 한계

- δ 격자는 여전히 0.5 간격이고, 격자 밖 값은 이웃 셀로 흡수된다. 잔차 자체를 줄이는 방법(연속 최적화)은 이 실험에 없다.
- 두 δ는 서로소인 두 층에 하나씩만 놓았다. 한 층 안에서 δ가 섞이거나 세 층이 동시에 움직이는 조건은 없다.
- 100장, 단일 family, 단일 예산. 판정은 위 산술로만 계산했고 사후 조정은 없다.
- `oracle`은 정답 점수를 쓰므로 비배포 상한이다. 표의 oracle 열은 깨끗한 점수의 성능이다.
