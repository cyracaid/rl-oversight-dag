# 행동별 보상 배분 비교의 실행 전 조건

같은 특징 전용 GNN이 16회 검토 후 남기는 결론 오류를 비교한다. A는 마지막의 기준 규칙 대비 오류 차이를 모든 행동에 준다. B는 각 행동 직전부터 끝까지 줄인 오류 수에서 같은 사례 기준 규칙의 같은 구간 감소량을 뺀다. 첫 행동의 두 값이 같고 두 경로 모두 단계별 변화량의 합이 처음과 끝의 차이와 같아야 한다. 오류 수는 행동이 끝난 경로를 같은 시뮬레이터에서 재생한 뒤 감사 기록에서 읽는다.

- A는 이전 실험의 `feature_only` 검증 선택 가중치를 사용한다. 기록된 훈련 코드·환경·버전·체크포인트·이력 파일을 대조하고 B가 각 학습 사례에서 기준 규칙의 오류를 재현하는지 확인한다. 시드별 0회차 검증 결과와 첫 학습 경로의 최종 오류도 대조한다.
- 두 방식은 시드 1–5, 시드당 384회, 정상·균등 잡음·유형 내 순열 각 128회, 같은 순서, 같은 초기 가중치와 확률적 선택의 난수 시드를 사용한다. 모델은 `GainActor("feature_only")`, 온도 0.12, Adam 학습률 0.003, 기울기 상한 5다. 검증 그래프 74000–74023에서 0·192·384회차의 세 조건 평균이 가장 낮은 모델을 선택한다. 동률이면 앞 회차를 쓴다.
- 평가 그래프 96000–96199와 에피소드 시드 +20000에서 같은 검토자·숨은 오류·전파 난수로 세 정책을 비교한다. 같은 그래프 안에서 검토 예산은 16회다. 평가 사례는 가중치 선택에 사용하지 않는다.
- 주 비교는 전체 유형 내 순열에서 B − A 평균 잔여 결론 오류다. 같은 학습 시드와 그래프의 차이를 유지하며 각각 10,000회 교차 재표집한다. 95% 구간의 상한이 0 미만이면 B의 개선을 지지한다. 정상·균등 잡음, 강한 피드백 규칙과의 차이, 각 시드와 최악 시드, 학습·검증 곡선은 보조 결과다.
- 초기 정책 진단은 각 시드의 첫 24개 학습 사례(조건별 8개)에서 가중치 갱신 없이 무작위 경로를 한 번씩 뽑는다. 한 경로에 두 보상식을 적용해 클리핑 전 기울기의 중심화된 제곱 거리 합의 평균(표본 공분산의 대각합), 0이 아닌 기울기 사이의 평균 코사인 유사도와 0인 기울기의 빈도를 비교한다.
