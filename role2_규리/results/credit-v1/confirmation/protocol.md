# 새 그래프에서의 규칙 비교

그래프 96000–96199의 전체 순열 결과에서 행동별 보상 B가 종료 보상 A보다 적은 오류를 남겨 [후속 계획](../../../후속실험계획.md)의 새 그래프 비교를 진행한다. 아래 선택은 98000–98199의 결과를 열기 전에 고정했다.

- 후보는 B의 검증 선택 가중치 5개 전부다. 별도 훈련 없이 시드에 같은 가중치를 준다.
- 조건은 Spike 그래프의 다섯 유형 각각에서 점수를 섞은 경우다. 검토 16회 후 그래프당 남은 결론 오류 수를 센다.
- 비교 대상은 ① 처음부터 점수를 무시하는 유형별 기본 오류 확률과 하류 영향 규칙, ② 공개 점수와 검토 피드백으로 점수 사용 여부를 고르는 하류 영향 규칙, ③ 첫 후보 6개와 다음 검토의 발견·미발견 분기를 살피는 기존 두 단계 계획이다. 앞선 전체 순열 실험에서 처음부터 점수를 무시한 정책이 항상 믿는 정책보다 유리해 고정 비교 대상으로 택했다.
- 모든 정책은 각 그래프에서 같은 숨은 상태와 검토자 난수를 사용한다. B에서 각 규칙을 뺀 평균 차이와 시드·그래프 교차 짝지은 95% 구간을 10,000회 재표집(난수 시드 20261112)으로 구한다. 세 비교의 상한이 모두 0 미만일 때만 세 규칙 모두보다 적은 오류를 남겼다고 판단한다. 점수가 모두 섞인 v3 합성 조건으로 적용 범위를 한정한다.
