# 사전 등록: 검증 후 전환(probe-then-decide) 실험

작성 2026-11-24, **실행 전**에 고정한다. 이 파일의 규칙·예측·판정 기준은 결과를 본 뒤 바꾸지 않는다.
바꿔야 한다면 새 파일(`PREREGISTER_VERIFY_V2.md`)을 만들고 이 파일은 그대로 둔다.

## 왜 하는가

`results/corruption-v1/`(200 그래프, seeds 3000–3199)에서 전역 평균 게이트는 두 방향으로 실패했다.

- 순위를 보존하는 전역 −1 이동에서 trust는 oracle보다 **+0.06**만 나쁜데, 게이트는 195/200을
  `noise`로 판정하고 유형 사전확률로 회귀해 **+1.82 [+1.63, +2.03]** 개의 추가 오류를 냈다.
- 실제 오류를 감추는 양수 이동(+3, error nodes)에서는 **0/200** 판정, trust는 **+3.21** 나빠졌다.

진단: 실패는 임계값이 아니라 **결정 변수**에 있다. 게이트는 "점수가 좋다 / 무정보하다"의 이분법만
갖고, 그 사이의 "순위는 살아 있지만 보정이 깨졌다"를 표현할 수 없다. 그리고 회귀 대상이 전역
사전확률이라, 잘못 발동하면 손실이 3배가 된다.

## 정책 정의 (동결)

- `oracle`: 손상되지 않은 점수, marginal. 비배포 상한.
- `trust`: 손상된 점수, marginal. 회귀 없음.
- `gate`: 기존 게이트. 그래프 평균이 `noise`에 가까우면 유형 사전확률, 아니면 `normal`.
- `verify`: 아래 절차. **사전확률로는 절대 회귀하지 않는다.**

`verify` 절차:

1. 같은 스냅샷에서 두 가설을 동시에 돌린다: `normal`(점수 그대로)과 `rank`(점수를 순위만 남기고
   재보정). 두 가설의 노드별 `P(flag)` 차이의 최댓값이 임계값 `T` 이하이면 probe 없이 `trust`와
   완전히 동일하게 16회를 쓴다.
2. `T`를 넘으면 `PROBES = 4`회를 `|P_normal(flag) − P_rank(flag)|`가 가장 큰 노드에 쓴다.
   매 probe마다 두 환경을 같은 행동으로 함께 진행하고(flag는 스냅샷만의 함수이므로 동일),
   관측된 flag로 로그우도비 `L = Σ log P(flag|normal)/P(flag|rank)`를 누적한다.
3. `L ≥ 0`이면 남은 예산을 `normal`로, `L < 0`이면 `rank`로 16회까지 marginal을 쓴다.
   판정은 한 번만 하고 되돌리지 않는다.

`rank` 재보정: 그래프 안에서 점수의 순위 `q = (rank + 0.5)/n`를 취해, **보정용 그래프
70000–70099의 깨끗한 점수 분포**에서 같은 분위수의 값으로 치환한다. 단조 변환 불변이라
순위는 그대로이고 크기만 복원된다. 정답·간선·검토자 난수는 쓰지 않는다.

동결 상수: `PROBES = 4`, `p_catch = 0.9`, `T = 보정 100그래프에서 max|ΔP|의 99백분위`,
판정 임계 `L ≥ 0`, 예산 16.

## 예측 (실행 전)

1. **순위 보존 손상**: `verify − trust ≤ +0.20` (uniform 100%·−1). 게이트의 +1.82를 없앤다.
2. **국소 과보정**: `verify ≤ trust` (uniform 50%·−3, 25%·−3). 여기서는 trust도 나쁘지만
   rank 재보정이 순위를 살려 oracle 쪽으로 당긴다.
3. **은폐형 손상은 못 고친다**: `verify − oracle ≥ +2.0` (error_nodes 100%·+3).
   순위 자체가 오염되므로 어떤 재보정도 복구할 수 없다. 이건 실패로 기록한다.
4. **오경보 없음**: 깨끗한 셀과 양수 shift(uniform)에서 `verify == trust` (probe 미발동).

## 판정 규칙 (동결)

- 주 엔드포인트: 같은 셀·같은 그래프에서 `verify − trust`와 `verify − oracle`의 짝지은 그래프
  부트스트랩(10,000회, seed 20261112).
- 성공: 예측 1과 2가 모두 성립하고 예측 4가 깨지지 않음.
- 부분 성공: 예측 1만 성립. 이 경우 "검증은 과보정만 막고 국소 손상은 못 고친다"로 보고.
- 실패: 게이트가 발동한 셀의 20% 이상에서 `verify > trust`. 이 경우 probe 비용이 이득을 넘는다는
  음성 결과로 보고하고, 게이트 수리를 중단한다.
- 예측 3은 성공/실패와 무관하게 그대로 보고한다.

## 한계 (미리 적음)

- `oracle`은 정답을 쓰므로 비배포. `rank` 재보정은 층별 분포가 같은 합성 Spike에서만 정당화된다.
- 단일 아키텍처(고정 marginal), 단일 그래프 family. 학습 정책은 이 실험에 없다.
- `T`의 99백분위는 보정 100그래프에 의존한다. 다른 손상 생성기에는 재적합이 필요하다.
- 탐색적 경계 측정이지 동결 가설의 확인 검정이 아니다. 다만 이 파일의 예측·판정 기준은 실행 전에
  고정한다.
