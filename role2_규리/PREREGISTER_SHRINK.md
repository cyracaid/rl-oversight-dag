# 사전 등록: 노드별 혼합 사후확률(shrink) 실험

작성 2026-11-24, **실행 전**에 고정한다. 아래 정의·예측·판정 기준은 3400–3599 결과를 본 뒤 바꾸지 않는다.
바꿔야 하면 새 파일(`PREREGISTER_SHRINK_V2.md`)을 만들고 이 파일은 그대로 둔다.

## 왜 하는가

`verify-v1`(seeds 3200–3399)은 사전 등록대로 **실패**했다. 전역 통계량 `max|ΔP|` 를 쓰는 한,
그 값은 "분포가 얼마나 움직였나"를 재고 "얼마나 해로운가"를 재지 못한다. 그래서 순위를 보존하는
−1 이동에서는 이득이 없고(정답은 trust), 무해한 +3 에서도 195/200 발동했다.

이번에는 판정 변수를 **노드별**로 바꾼다. 전역 이분법 대신, 각 노드의 점수가 "정상 분포에서 나왔는가,
아니면 이동된 분포에서 나왔는가"를 혼합모형으로 계산해 그 사후확률을 정책에 넣는다.

## 정책 `shrink` (동결)

관측 가능한 것만 쓴다: 공개 점수 `c`, 노드 타입과 타입별 사전확률 `r_i = rates[type_i]`, 간선·그래프 구조.
정답(`source_errors`), 간선 동전, 검토자 난수는 쓰지 않는다. 게이트처럼 이분법으로 되돌리지 않고,
노드마다 연속적으로 사후확률을 다시 계산한다.

환경의 공개 코드(`dag_role3/environment.py: initial_belief`)가 이미 다음 생성모형을 가정한다.
이 상수를 그대로 쓴다.

```
z_i = logit(c_i)
bias_i = -0.4 * (r_i - 0.15)
정상:      z_i | b ~ N(mu_b + bias_i, SIGMA),  mu_1 = -1.5, mu_0 = +1.5, SIGMA = 1.2
```

여기에 "점수가 이동됐을 수 있다"는 대립가설을 더한다.

```
이동:      z_i | b, δ ~ N(mu_b + bias_i + δ, SIGMA)
δ 격자:    {±0.5, ±1.0, ±1.5, ..., ±4.0}   (16개, 균등 가중)
노드별 이동 사전확률: π   (단일 스칼라, 보정 블록에서만 적합)
```

노드별 혼합 사후확률:

```
L_b  = φ((z_i - mu_b - bias_i)/SIGMA)
M_b  = (1/16) Σ_δ φ((z_i - mu_b - bias_i - δ)/SIGMA)
joint_b = r_i^b (1-r_i)^(1-b) · [ (1-π) L_b + π M_b ]
q_i = joint_1 / (joint_0 + joint_1)
```

`q_i` 를 `initial_belief` 대신 `_belief_base` 로 넣고, 나머지는 `trust` 와 완전히 같은
marginal 규칙·예산 16회를 쓴다. 즉 **정책은 하나도 안 바꾸고, 입력 사후확률만 노드별로 다시 계산**한다.

노드 독립을 가정한다는 점을 명시한다. 실제 손상은 locality 단위(all-or-none)라서 이 가정은
증거를 과소평가하는 **보수적** 방향이다.

## π 적합 (동결)

- 보정 그래프: **70000–70029** (30개), 에피소드 시드 `graph_seed + 20000`.
- π 격자: `{0.00, 0.05, ..., 0.60}` (13개).
- 각 π 에 대해 (a) 깨끗한 셀 평균, (b) 손상 격자 112셀 평균 잔여 오류를 계산한다.
- **허용 집합** = `clean_mean(π) − clean_mean(trust) ≤ 0.05` 를 만족하는 π, 그리고 항상 0을 포함.
- 허용 집합 안에서 **손상 격자 평균이 최소**인 π 를 고른다. 동률이면 작은 π.
- π 는 한 번만 적합하고 3400–3599 에는 재적합하지 않는다.

## 예측 (실행 전)

1. **게이트의 오경보를 반복하지 않는다**: uniform 100 %·−1 에서 `shrink − trust ≤ +0.20`
   (게이트는 +1.845 였다).
2. **은폐형을 실제로 고친다**: error_nodes 100 %·+3 에서 `shrink − trust ≤ −0.30`.
   이동 +3 을 가정한 혼합모형이 그 노드들의 사후확률을 다시 올려야 한다.
3. **깨끗한 비용이 작다**: 깨끗한 셀에서 `shrink − trust ≤ +0.05`.
   (극단 점수는 "반대 상태 + ±3 이동"과 관측적으로 구별되지 않으므로 0은 기대하지 않는다.)
4. **국소 과보정을 악화시키지 않는다**: uniform 50 %·−3 과 25 %·−3 에서 `shrink − trust ≤ 0`.

## 판정 규칙 (동결)

- 주 엔드포인트: 같은 셀·같은 그래프에서 짝지은 그래프 부트스트랩(10,000회, seed 20261112) 95 % 구간.
- **성공**: 예측 1–4가 모두 성립.
- **부분 성공**: 예측 2와 3이 성립하고, 1 또는 4가 기준을 0.20 이내로 못 넘김.
- **실패**: 예측 2가 불성립(은폐형을 못 고침) 또는 예측 3이 0.10 초과로 불성립.
- 성공/실패와 무관하게 전 격자와 π 를 그대로 보고한다.

## 한계 (미리 적음)

- 혼합모형의 δ 격자가 평가 격자의 이동 범위와 같은 구간이다. 모형 선택의 순환 위험이 있고,
  다른 손상 생성기(예: 곱셈적 왜곡, 부분 구간만 이동)에는 그대로 전이되지 않는다.
- 정규분포·등분산·노드 독립 가정은 이 합성 Spike 생성기의 것이지 일반 주장이 아니다.
- π 하나로 전체 손상률을 요약한다. 실제로는 그래프마다 손상 여부가 다르다.
- `oracle` 은 정답을 쓰므로 비배포. 단일 marginal 규칙, 단일 그래프 family, 학습 정책 없음.
