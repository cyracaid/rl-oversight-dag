3. Five people, five deliverables

WP0

P1 · lead / protocol

One job: make everyone's numbers comparable
  • eval.py: the single recall / CI implementation
  • table template, seed protocol, pairing rule
  • reject any table without a CI or a script path
Acceptance: others import your eval instead of copying it. Frozen by D2.
WP1

P2 · policy gradient

Two arms: does RL lose on representation, or does the model just carry the win?
  • Arm A: belief / static / observed / belief-greedy, 5 seeds × 200 held-out
  • Arm B: perturb λ (×0.5, ×2) and the confidence calibration, rerun the same four
  • publish every seed, not the best one
Acceptance: two tables with CIs. Arm A decides Option 1/2; Arm B says whether the winner depends on a correct model.
Blocked by: WP2 freeze.
WP2

P3 · environment

The choke point: move the environment and every number dies
  • tag and freeze the synthetic generator
  • define the item schema for transfer datasets
  • write the KAIST adapter
Acceptance: --dataset kaist runs end to end; after the freeze, changing the env means a new version and a full rerun.
WP3 · WP4

P4 · baselines / controls

Survey first, implement two; diagnostics only under Option 2
  • five candidates: VOI, MCTS, BC, offline RL, transformer
  • implement the two cheapest on the same harness
  • diagnostics: credit correlation, return variance, four interventions
Acceptance: a one-page fit/effort/risk table plus two working baselines.
WP5

P5 · you / data

The only truly independent job, and it decides whether this generalizes
  • KAIST → GO → Manchester, verifying licence and fields
  • open the real files, not the abstract
  • no data in the repo, only aggregate numbers
Acceptance: every row has a verifiable licence and a load command that runs.

3. 다섯 명, 다섯 개의 산출물

WP0

P1 · 팀장 / 프로토콜

한 가지 일: 모두의 숫자를 비교 가능하게 만든다

  • 표 템플릿, 시드 프로토콜, 페어링 규칙

WP1

P2 · 정책 경사

두 갈래: RL이 표현에서 지는가, 아니면 모델이 이기는가

  • Arm B: λ(×0.5, ×2)와 신뢰도 보정을 흔들고 같은 네 정책 재실행
  • 가장 좋은 시드가 아니라 모든 시드를 공개
검수: CI가 있는 표 두 개. Arm A가 Option 1/2를, Arm B가 '승리가 모델 정확도에 의존하는가'를 결정.
차단: WP2 동결.
WP2

P3 · 환경

병목 본인: 환경이 움직이면 모든 숫자가 죽는다
  • 합성 생성기를 태그로 동결
  • 전이 데이터셋의 item 스키마 정의
  • KAIST 어댑터 작성
검수: --dataset kaist 한 명령으로 끝까지; 동결 후 환경 변경 = 새 버전 + 전면 재실행.
WP3 · WP4

먼저 조사, 두 개 구현; 진단은 Option 2일 때만
  • 다섯 후보: VOI, MCTS, BC, 오프라인 RL, 트랜스포머
  • 가장 싼 두 개를 같은 harness에 구현
  • 진단: 크레딧 상관, 리턴 분산, 네 가지 개입
검수: fit/effort/risk 한 페이지 표 + 작동하는 베이스라인 두 개.
WP5

검수: 모든 행에 검증 가능한 라이선스와 실행되는 로드 명령.
