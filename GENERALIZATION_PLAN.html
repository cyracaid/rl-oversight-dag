Generalization plan — team work packages

The goal is not another result on the sleep queue. It is a protocol that survives a change of cohort and a change of domain.

Status: not done, not verified. The belief-conditioned result is a single run. Nothing below assumes it holds until WP1 reproduces it.

3. Work packages

  • eval.py: the only recall / CI implementation
  • table template, seed protocol
  • reject any table without a CI or a script path
Acceptance: others import your eval instead of copying it. Frozen by D2.
WP1

P2 · verify

Does RL lose on representation or on credit assignment?
  • belief / static / observed / belief-greedy
  • 5 seeds × 200 held-out × paired bootstrap
  • publish every seed
Acceptance: one command, one table; a negative result is still a delivery.
Blocked by: WP2.
WP2

P3 · environment

The choke point: move it and every number dies
  • tag and freeze the generator
  • define the item schema
  • write the KAIST adapter
Acceptance: --dataset kaist runs end to end.
WP3·4

P4 · baselines

Survey first, implement two
  • VOI, MCTS, BC, offline RL, transformer
  • two cheapest on the same harness
  • diagnostics only under Option 2
Acceptance: one-page fit/effort/risk table + two working baselines.
WP5

P5 · datasets

The only truly independent job
  • KAIST → GO → Manchester, licence and fields verified
  • open the real files
  • no data in the repo
Acceptance: every row has a licence and a load command that runs.

4. Rules for every package

  • One table, one script. If a number cannot be regenerated by a command, it does not exist.
  • Paired comparisons only, bootstrap CI, at least 5 seeds.
  • Report the interval, not the winner. Below ~10 pp on the real queue is noise.
  • No dataset in the repo. Code and aggregates only.
  • Status labels: every claim is verified / unverified / retracted.

5. Dependencies, honestly

Only two tasks are independent: the dataset survey and the reading half of the model survey. Everything else is on one chain.

4. 모든 패키지에 적용되는 규칙

  • 표 하나, 스크립트 하나. 명령으로 재생성할 수 없는 숫자는 존재하지 않는다.
  • 짝지은 비교만, 부트스트랩 CI, 최소 5 시드.
  • 승자가 아니라 구간을 보고하라. 실제 큐에서 ~10pp 이하는 노이즈다.
  • 데이터는 저장소에 넣지 않는다. 코드와 집계만.
  • 상태 표기: 모든 주장은 verified / unverified / retracted.
