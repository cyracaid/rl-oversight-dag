목표 왜 진짜 문제인가 돌아간 길 (부정적 결과) 재구성: 그래프 MDP 수학 결과 소거 규모 (N=500) 실제 파이프라인 관련 연구 결정 가이드 SciForge 착지 팀 검증

사람은 어느 항목을 먼저 검토해야 하는가?

연구 증거 사슬의 검토 계층을 위한 강화학습.

수면 데이터: Maia ten Brink (Stanford Psychophysiology Lab)와 1년 협업 EMA.
응용 대상: SciForge — Zhangyang Gao (AI4Science, Shanghai AI Lab)가 개발.

기계는 도장을 찍지 않음 읽기 전용 순위 사람이 판정해야 영수증

우리가 만드는 것

AI가 이미 수면 일기를 정제하고, 문헌에 라벨을 달고, 분석을 돌립니다. 그 출력은 서로 의존합니다: 시간이 반대로 쓰이면 잠복기가 틀리고, 수면 효율이 틀리고, 결론이 믿을 수 없게 됩니다.

사람이 전부 확인할 수는 없습니다. 강화학습으로 읽기 전용 제안기를 학습합니다: 다음에 어떤 노드를 검토할지, 결론에 도달하는 오류를 줄이기 위해서.

기계는 도장을 찍지 않습니다. 제안기는 읽기 전용 조언자입니다. 검토는 사람이 판정을 기록할 때만 영수증이 됩니다.

왜 진짜 문제인가

우리 실험실 수면 일기: 13,990 기록, 237명, Maia ten Brink와 1년 협업 EMA. 사람이 고친 것은 75건(0.54%)입니다.

그 75건은 흩어져 있지 않습니다 — 76%가 같은 실수(order_error: 시간 순서 반대, p < 0.0001)입니다.

실수는 제자리에 머물지 않습니다. 시간이 틀리면 → 잠복기가 틀리고 → 효율이 틀리고 → 결론이 틀립니다.

그래서 "얼마나 검토하느냐"보다 "무엇을 검토하느냐"가 더 중요합니다. 예산은 작습니다. 76% 유형의 상류에 쓰는 것이 값집니다.

돌아간 길 (솔직한 부정적 결과)

첫 버전은 밴딧이었습니다. 결과: 간단한 임계값이 Q-러닝을 이겼습니다 (2.81 vs 3.38).

이유: 항목별 검토는 그래프를 평평하게 만듭니다. 76%가 한 유형이라 최적 정책은 if-규칙으로 무너집니다.

이 실패를 숨기지 않았습니다. 재구성의 이유입니다.

재구성: "이 항목을 검토할까?"에서 "다음 노드는?"으로

증거를 방향 그래프로 그립니다. 에이전트가 걷고 노드를 하나 골라 검토합니다. 좋은 검토는 하류를 바꿉니다.

진짜 MDP입니다: 상태에 그래프와 남은 예산, 보상은 마지막에 옵니다.

프론트 일기 행 / 코드 / 주장에 하이라이트-질문 → 검토 흔적 (영수증 아님) ↓ 검토층 신념 그리디 / GNN / 임계값 제안기 → "이것 먼저 검토" (읽기 전용) ↓ 사람이 "판정" 클릭 백엔드 SciForge 증거 DAG + 영수증 → 기계 도장 없음, append-only

수학 골격 (RL 수업의 메인)

1. 인과 전파 (DAG 개입). \(X_v \in \{0,1\}\) (1=올바름). 에지 \((u,v)\), 가중치 \(w_{uv} \sim U(0.5, 1.5)\):

\[ P(X_v = 0 \mid X_u = 0) = 1 - \exp(-\lambda\, w_{uv}), \quad \lambda = 0.8 \]

노드 \(v\) 검토 = do\((X_v := 1)\). 인과 개입이지 상관이 아닙니다.

2. MDP. 상태 = 그래프 지식 + 잔여 예산. 행동 = 다음 노드(또는 stop). 보상 \(r_T = -\#\text{sink 오류}\). \(\gamma < 1\).

3. CMDP 라그랑지안. \(\max_\pi \min_{\lambda \ge 0} J(\pi) + \lambda\,(B - C(\pi))\). 오늘 주 방법은 GNN + 고정 예산 REINFORCE; 이중 critic CMDP는 진행 중.

4. 신념 위의 적응형 그리디. 파티클 필터가 어떤 노드가 틀렸을지 추적하고, 매 단계 결론 오류의 기대 감소가 가장 큰 노드를 검토한 뒤 검토 결과로 신념을 갱신합니다. N=500 스케일프리에서 81 → 12.8. 같은 규칙을 실제 오류에 쓰면(오라클) 3.6이지만, 실제 정책은 참값을 볼 수 없습니다.

5. 정보 이득 보상 (설계, 아직 미실행). \(R = \alpha\, \Delta H_v - \beta\, \mathrm{Cost}(v)\)

6. 정책 경사 (주 방법). \(\nabla_\theta J = \mathbb{E}[ \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, A_t ]\)

GNN 점수기: \( h_v = \tanh(W_{\text{self}} x_v + W_{\text{neigh}} \frac{1}{|N(v)|}\sum_{u\in N(v)} x_u ) \)

7. worst-of-n. 검토 안 된 오류 하나가 결론을 무효화할 수 있습니다(HealthBench). 시드 3개 중 최악: noise 5.20, oracle 0.80.

결과 (N=80)

모든 수치는 결론에 도달한 오류 수입니다. 낮을수록 좋습니다. AI 생성, 팀원 재현 필요.

위 표는 시드 1–20이며 쉬운 그래프로 드러났습니다. 처음 보는 그래프 200개에서: 임계값 1.41, 구조적 그리디 1.45, 신념 그리디 1.14, GNN 1.56. 배포 가능한 신념 그리디가 모든 학습 정책을 이기고(GNN − 신념 그리디 = +0.42 ± 0.15), GNN에 검토 결과를 넣어도 도움이 안 됐습니다.

DQN은 무작위로 퇴화합니다 — 희소 종료 보상은 가치 함수를 못 먹입니다. 그래서 정책 경사가 맞는 도구입니다.

1판 밴딧은 임계값에 졌습니다 (2.81 vs Q-러닝 3.38). 그 실패가 재구성의 이유입니다.

규모: N = 500, 세 그래프 족

같은 개입 모델. 예산 50(10%). 5 시드. 모든 정책이 같은 난수 흐름을 재생합니다. 신념 그리디는 배포 가능, 오라클 그리디는 실제 오류를 읽는 상한입니다. RL 아님.

정직한 범위: 이 500노드 수치는 휴리스틱이지 RL이 아닙니다.

관련 연구

HealthBench(2025-05)는 의미 있고, 신뢰 가능하고, 비포화인 rubric과 worst-of-n 신뢰성으로 평가하는 법을 가르쳤습니다.

BioBasicsBench(OpenAI + Ligo, 2026-11-06)는 에이전트가 원시 습식 증거를 읽고 오류와 불충분을 잡는지 물었습니다. 최고 모델 66.7%. 실패: 가정이 대조를 이기는 것, 모순 관찰 무시, 집계 오류. 우리 76% order_error는 같은 종입니다.

L2D: Mozannar & Sontag ICML 2020; FALCON arXiv:2604.00904; SLTD arXiv:2109.06312; Reid et al. arXiv:2409.20489; KL-PBD arXiv:2610.15128; Oversight arXiv:2606.08919. 연쇄: Data Cascades CHI 2021; Finkel EMNLP 2006; From Spark to Fire arXiv:2603.04474. 예산+노드 선택: WS-option arXiv:2502.05537; Mattick arXiv:2310.00112.

채택: 의미 있음 / 신뢰 가능 / 비포화; worst-of-n; 부분 점수 영수증; 오류 탐지 1급 기술; "증거가 결론을 지지하지 않는다" 행동.
추가: 예산이 걸린 순차 검토 + 의존성 그래프 — 그들이 만들지 않았습니다.

SciForge 착지

SciForge에는 이미 증거 DAG, 사람 검토 영수증, 감사 계층이 있습니다. 이 프로젝트는 그 위에 검토 우선순위 제안기를 얹습니다. 기록 규칙은 바꾸지 않습니다.

프론트 일기 행 / 코드 / 주장에 하이라이트-질문 → 검토 흔적 (영수증 아님) ↓ 검토층 신념 그리디 / GNN / 임계값 제안기 → "이것 먼저 검토" (읽기 전용) ↓ 사람이 "판정" 클릭 백엔드 SciForge 증거 DAG + 영수증 → 기계 도장 없음, append-only

단계: (1) 합성 + 내보낸 비식별 DAG 오프라인 평가; (2) 검토 화면 옆 읽기 전용 제안; (3) 증거사슬 소유자(郑心)와 영수증 악수.

검증 상태

AI 생성, 팀원 재현 필요. 확인: 인용, 실데이터 수치(2026-11-09: 13,990 / 237 / 75 / 76%).

미확인: 모든 시뮬레이션 수치; 시뮬레이터 설계; 표 간 무검토 차이(5.62 vs 5.90); "직접 선례 없음"(다시 검색); 논문 전문; 모델이 틀렸을 때의 신념 그리디; GNN+PPO 미수렴; 이중 critic CMDP 미구축; SciForge 신뢰도 필드; 합의/하드 분할 미실행.
