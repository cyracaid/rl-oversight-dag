The RL plan, in detail

Course-facing only. No external partner, no restricted data, every number from one script.

1. G0 — the experiment that decides the paper

Give the policy the belief posterior (marginal, entropy, reviewed mask) so it sees exactly what belief greedy sees. Everything else unchanged.

G0 resultReadingCourse claim
RL ≥ belief greedy (CI excludes 0)the loss was representationOption 1 — RL is the method
RL < belief greedythe loss is credit assignmentOption 2 — the analysis is the result

Arm B — the assumption test. Belief greedy is model-based: it assumes the propagation probability and the confidence calibration are correct. Perturb exactly those (λ × 0.5 and × 2.0, confidence shifted), rerun the same four policies on the same graphs. If belief greedy degrades and RL does not, RL has a niche; if both degrade, the model is the advantage; if belief greedy is robust, the "information beats the learner" claim gets stronger. Same sweep, one extra axis.

2. MDP, stated once

ElementDefinition
Stateper node: type, confidence, downstream count, reviewed mask, budget left; belief variant adds posterior marginal and entropy
Actionpick an unreviewed node, or stop
Transitionreview → observation (flagged w.p. p_catch) → fix only at the source; recompute descendants
Rewardterminal only: −(# wrong sinks). Variants: potential shaping, n-step
Horizonbudget B (80-node: 16), γ < 1

4. Experiment matrix

AxisLevels
environment80-node synthetic (main), N=500 modular/BA/ER (heuristics), N=21 real pipeline
seeds5 training seeds × 20k episodes
evaluation200 held-out graphs, paired by graph, bootstrap CI
state ablationstatic / observed / belief
reward ablationterminal only / potential shaping / n-step (3, 5)
budget8, 16, 32 (eval only)

Reporting rule. Every comparison is a paired difference with a CI. A point estimate without a CI does not enter the paper — five seeds already fooled us once.

5. If RL loses: four diagnostics

  1. Credit assignment. Correlation between per-step advantage and the action's realized contribution.
  2. Return variance. Terminal-only reward over a 16-step horizon at fixed policy.
  3. Interventions. Potential shaping, n-step, batch size, 100k episodes.
  4. Information control. Already covered by G0.

The write-up becomes: policy gradient fails here because X, and here are three tests that would have falsified X.

7. Definition of done

Option 1: belief-conditioned RL beats belief greedy on 200 held-out graphs, paired CI excluding 0, 5 seeds, and the gain survives the state ablation.
Option 2: a named mechanism, at least one intervention that moves RL toward parity or provably cannot, and the information control reported.

RL 계획, 상세

과정용. 외부 파트너 없음, 제한 데이터 없음, 모든 숫자는 하나의 스크립트에서.

1. G0 — 논문의 방향을 결정하는 실험

정책에 belief 사후분포(주변확률, 엔트로피, 검토 마스크)를 준다. belief greedy가 보는 것과 동일하게.

G0 결과해석과정 주장
RL ≥ belief greedy (CI가 0 제외)손실은 표현 문제Option 1 — RL이 방법
RL < belief greedy손실은 크레딧 할당Option 2 — 분석이 결과

Arm B — 가정 시험. belief greedy는 모델 기반이다: 전파 확률과 신뢰도 보정이 맞다고 가정한다. 바로 그 둘을 흔들고(λ × 0.5, × 2.0, 신뢰도 이동) 같은 네 정책을 같은 그래프에서 재실행한다. belief가 무너지고 RL이 버티면 RL에 생태계가 생기고, 둘 다 무너지면 승리는 모델의 것이며, belief가 견고하면 "정보 > 학습기" 주장이 더 강해진다. 같은 스윕, 축 하나 추가.

보고 규칙. 모든 비교는 CI가 있는 짝지은 차이. CI 없는 점추정은 논문에 넣지 않는다 — 5 시드에 이미 한 번 속았다.

5. RL이 지면: 네 가지 진단

  1. 크레딧 할당. 단계별 advantage와 실제 기여의 상관.
  2. 리턴 분산. 고정 정책에서 16스텝 종료 보상의 분산.
  3. 개입. potential shaping, n-step, 배치 크기, 100k 에피소드.
  4. 정보 대조. G0가 이미 처리.

서술은 이렇게 된다: 정책 경사는 여기서 X 때문에 실패하며, X를 반증했을 세 가지 검사를 함께 보고한다.

强化学习计划（细化）

只面向课程。无外部合作方、无受限数据、每个数字来自一个脚本。

1. G0 —— 决定整篇写法的实验

把 belief 后验（边际概率、熵、已审掩码）喂给策略，让它看到的和 belief greedy 完全一样。

G0 结果解释课程主张
RL ≥ belief greedy（CI 排除 0）之前输是表示问题Option 1 — RL 是方法
RL < belief greedy输是信用分配Option 2 — 分析即结果

Arm B —— 假设检验。belief greedy 是模型基的：它假设传播概率与置信度校准都是对的。 把这两个恰好弄错（λ × 0.5、× 2.0，置信度平移），同四条策略在同一批图上重跑。 belief 崩而 RL 不崩 → RL 有生态位；两者一起崩 → 赢的是模型；belief 稳 → 「信息 > 学习器」更硬。 同一次 sweep，多一个轴。

2. MDP

要素定义
状态每节点：类型、置信度、下游数、已审掩码、剩余预算；belief 变体加后验边际与熵
行动选未审节点，或停止
转移审阅 → 观测（以 p_catch 报错）→ 只修源头；重算下游
奖励仅终局：−（错误 sink 数）。变体：potential shaping、n-step
时间跨度预算 B（80 节点：16），γ < 1

5. 如果 RL 输了：四个诊断

  1. 信用分配。每步 advantage 与该步实际贡献的相关性。
  2. 回报方差。固定策略下 16 步终局奖励的方差。
  3. 干预。potential shaping、n-step、batch、100k episode。
  4. 信息对照。G0 已经覆盖。

写法：策略梯度在这里失败，原因是 X，并附上三个本可以证伪 X 的检验。
