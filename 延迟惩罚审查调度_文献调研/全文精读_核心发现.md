# 全文精读：四篇核心论文 + 你们的真实差异

> 更新：2026-11-08（读全文后）
> 已读全文：FALCON(2604.00904)、SLTD(2109.06312)、Online Deferral Budget(2409.20489)、KL-PBD(2610.15128)

## 0. 最重要的发现（一句话）

读了四篇全文后，你们文档 §2 的两个"事实"——(1) 错误不随机、按类型聚集；(2) 未审查错误被下游复用、到结论才暴露——**四篇里没有任何一篇做了这两个结构**。它们覆盖了你们的疲劳/预算/在线/延迟反馈组件，但都**没有**做"错误沿证据链往下游传播、到结论才惩罚"这个真正让你们与 bandit/FALCON 不同的东西。

所以：**你们不是完全没有空间。但空间只在一个地方——把 §2 那两个事实做成真结构，而不是现在 §4 的"结尾惩罚 + 同类型加罚"弱代理。**

## 1. 每篇的"延迟"到底指什么（全文精读的核心价值）

| 论文 | 它说的"延迟/长期/顺序"实际指什么 | 等于你们"错误扩散到结论"吗 |
|---|---|---|
| **FALCON** | 顺序依赖只经"工作量累加器 ρ"：现在 defer 通过疲劳改变未来人类准确率。奖励是**每步即时**准确率 | ❌ 否。无错误传播、无依赖图、无延迟惩罚 |
| **SLTD** | defer 的**长期后果**：现在 defer vs 下步 defer 对最终 outcome 的价值差；非平稳 MDP 动力学；传播的是"不确定性" | ⚠️ 部分。它传播的是医疗 MDP 的 state 演化，不是"证据条目组合成结论" |
| **Online Deferral Budget** | **无延迟**。奖励即时（选了 arm 才知道结果 = bandit 反馈，不是延迟惩罚） | ❌ 否 |
| **KL-PBD** | 延迟 = **队列**延迟：label 要等专家服务完才拿到。代价仍每步计（错误成本/专家成本/队列持有成本），终局只是清空队列的代价 | ⚠️ 部分。它的"结论"是有限视界终局成本，不是"下游步骤复用错误" |

**一句话：你们声称的差异点 #1（漏错代价到达得晚、扩散到结论），四篇没有任何一篇是那个结构。**

## 2. FALCON 全文要点（离你们最近的）

- **状态** s_t = (x_t, ρ_t)：当前样本 + 累积人工工作量
- **动作** {AI, Human}
- **疲劳曲线** w(ρ)：两段式——warm-up（二次增长）→ fatigue（sigmoid 衰减）。参数 (w0, wpeak, wbase, ρ̂, ρ̄, k)，来自认知心理学文献
- **人预测**：噪声率 η_t = 1 − w(ρ_t)，答对概率 1−η_t，答错时均匀翻到 K−1 个错类之一
- **工作量更新** ρ_{t+1} = ρ_t + 1(若 Human)，ρ_1 = 0
- **奖励** r = I[ŷ = y]（**即时准确率**）
- **约束**：人类工作量上下界（等价 coverage），CMDP + PPO-Lagrangian，双拉格朗日乘子 λ_u（防过度 defer）/λ_l（防不足 defer）
- **架构**：backbone CNN → 视觉特征 ‖ workload embedding → concat → **Resettable S5**（状态空间序列模型，线性复杂度，追踪数百步时序）→ 3 head（policy π / reward value V_r / cost value V_c）
- **基准 FA-L2D**：Cifar100、Flickr、MiceBone、Chaoyang（⚠️ 注意是 **CIFAR-100 不是 CIFAR-10**）
- **baseline**：Mozannar & Sontag、Madras、L2D-Pop(Tailor 2024)、EA-L2D(Strong 2025)
- **卖点**：零样本泛化到未见专家/不同疲劳模式；coverage 严格在 (0,1) 时自适应协作 > AI-only 或 human-only
- **代码**：github.com/zhengzhang37/FALCON

**对照你们 §3 状态（5 项）**：你们有"条目类型 + 置信度 + 剩余预算 + 过往审查结果 + 疲劳度"。FALCON 有"特征 + 累计工作量"。你们多出的**"条目类型"**（= 错误按类型聚集）是 FALCON 没有的——FALCON 把人建模成"对/错 + 随机翻错类"，**没有"同一类型系统性出错"的聚集结构**。这是你们能站住的第一根柱子。

## 3. SLTD 全文要点

- 离线 **model-based RL**，非平稳 MDP（医疗）
- 核心：defer 当且仅当"现在 defer"的价值 > "延迟到下一步 defer"的价值，含未来 defer 的混合策略 π_mix
- Bayesian RL + 后验采样 + 动态规划；deferral 概率 g̃(s,t) 迭代 refine
- 分解传播不确定性：epistemic（加数据可减）vs aleatoric（不可减）
- 数据：synthetic、Simglucose 糖尿病、EuResist HIV
- baseline 含 myopic 的 Mozannar/Madras，SLTD 显著更优

→ 这是"延迟代价/长期后果"最强的先例，但领域是医疗 MDP，不是证据链条目。

## 4. Online Deferral Budget 全文要点

- 双臂 contextual bandit + 预算；full-info vs bandit 反馈
- GLM 奖励/成本 + 乐观估计（UCB）+ 拉格朗日 γ
- regret Õ(d√T · OPT/B)
- 数据：synthetic、Knapsack（真人类 396 人）、ImageNet16H（真人类 145 人）
- **关键 baseline：BestReject** = 知道模型期望奖励、按阈值 defer 的最优"无人类信息"策略。**这正是批评要你们加的"按类型分别校准阈值"baseline！** 他们发现：互补专长场景下，算法 vs BestReject 差距不大（诚实报告了这一点）。

---

## 5. KL-PBD 全文要点

- 在线，每轮 query + LLM self-confidence level J ∈ [K]
- 未知条件准确率 h*，从"选择性 + 队列延迟"的专家反馈学
- KL 下置信界（悲观）：证据不足时偏 defer 以获取信息，但 congestion-aware
- regret O(K log T / γ) gap-dependent，Õ(√KT) worst-case，**含匹配下界**（optimal up to log factors）
- 数据 GSM8K/NuminaMath/MedMCQA + Qwen
- 明确引 Reid et al. 2024（= Online Deferral Budget）为"online deferral under budget"先例

## 6. 你们的真实差异（sharpened，诚实版）

四篇没覆盖的、你们可能独有的是**三件事的组合**：

1. **错误按类型聚集**（FALCON 无；其他三篇也无"类型级系统性错误"结构）——你们 §2 事实一
2. **错误沿依赖图/证据链往下游传播、到结论才惩罚**（四篇都无；SLTD 最接近但传播的是医疗 MDP state）——你们 §2 事实二
3. 用**真实研究数据（睡眠/文献标注）**验证 1+2 是否成立

**但：** 你们现在 §4 只实现了"结尾惩罚 + 同类型持续出错加罚"——这是 1+2 的**弱代理**，不是真结构。批评说的"把传播做成真结构（依赖图，错误沿图往下游传）"必须落地，否则 2 不成立，项目退回"CIFAR-10 玩具弱化版 FALCON"。

## 7. 下一步（更新后）

1. **落地依赖图传播**：把"条目之间有依赖、错误沿图往下游传"做成真 MDP，而不是结尾罚一下。这是你们与四篇论文唯一不可否认的分界线。
2. **基线必须加 BestReject 式"按类型校准阈值"**：Online Deferral Budget 已这么做（见其 Fig 3 的 BestReject），照抄思路，并诚实报告学习策略在哪些条件下不更好。
3. **用真实睡眠/文献标注数据验"类型聚集"假设**：这是把项目从 CIFAR-10 玩具救回来的唯一实证路径。
4. **补查"data cascades / ML pipeline error propagation"文献**（Sambasivan et al. 2021 CHI "Data Cascades in High-Stakes AI" 等）：确认"错误沿管道传播"是否已有定型结论——这决定你们的"证据链传播"还剩多少空间。这一步我下一步帮你查。
