# 3번 역할 구현 — 3차 개정 검토와 결과

첨부한 변경내역을 기준으로 이전 구현을 다시 검토하고 코드·학습·평가·설명서를 수정했다. 이번 작업에서 학습량은 GNN 1,000회, DQN 300회, 훈련 시드는 3개, 검증 사례는 30개, 최종 시험 사례는 유형별 100개로 정했다. 이 수치는 이번 구현 검증을 위해 선택한 실험 규모다.

## 보상 변경의 확인

환경이 주는 원래 보상은 마지막 검토에서 −잔여 오류 수다. DQN의 학습용 보상에 Φ(다음 상태) − Φ(현재 상태)를 더한다. Φ는 관측 가능한 결론 오류 추정확률 합계의 음수이며 종료 상태에서는 0이다.

전체 회차에 걸쳐 합하면 중간 Φ가 상쇄되어 ‘원래 총보상 − 초기 Φ’가 남는다. 초기 상태가 같으면 초기 Φ는 행동 순서와 무관하므로 최적화 목표를 유지한다. 이 관계를 자동 테스트에서 확인했다. 최종 평가에는 환경의 실제 잔여 오류 수를 사용한다.

## 검증 범위

자동 테스트 27개가 통과했다. 추가한 9개 테스트는 입자 복구 시 과거 수정 재적용, 작은 그래프의 해석적 사후확률과 비교, marginal 수치 미분, 보상 합의 상쇄, 표본 불변성, 잘못된 입력 차단, 감사 기록의 독립성, 리플레이 입력 보존, DAG 외부 변경 방지를 확인한다.

학습 실행 경로는 80노드 모델 세 시드의 전체 실행과 500노드 BA의 GNN, 500노드 ER의 DQN 각 1회로 확인했다. GNN static 변형도 1회 실행했다. 500노드 학습 검증은 실행 가능성을 확인한 것이며 학습 성능의 최종 평가는 Spike에 한정한다.

## 결과 해석 범위

모든 오류·신뢰도는 모의 생성한 값이다. 공개 전파 확률과 오류 발생 사전분포를 알고 있다고 가정한다. 실제 LLM 오류의 실측 검증은 후속 과제다.

입자 필터에도 재표집 후 다양성 감소, 낮은 유효 표본 수, 복구 실패 가능성이 있다. marginal은 공유 경로의 상관관계를 생략한 평균장 미분 근사다. 필터의 정확도와 검토 정책의 성과는 별도로 확인해야 한다.

구버전과 이번 학습 비교에는 기준 보상·학습 보상·검증 선택·학습량 변경이 동시에 포함된다. 개선 전체의 효과를 보여주며 각 변경의 단독 기여를 분리하는 실험은 수행하지 않았다. 학습 보상 변경의 우수성만을 독립적으로 주장할 수 없다.

## 새 시험 사례에서의 최종 결과

유형별 100개 사례, 총 500개 환경을 사용했다. 모든 정책은 해당 유형에서 같은 사례를 공유한다. 정책별 실행 기록은 3,600행이다. 아래 숫자는 남은 결론 오류의 평균이며 작을수록 좋다.

| 그래프 | 신뢰도순 | marginal | 감소량 [대응 95% 구간] |
|---|---:|---:|---:|
| spike | 1.03 | 0.66 | 0.37 [0.20, 0.56] |
| modular | 10.59 | 8.78 | 1.81 [1.10, 2.56] |
| ba | 29.65 | 20.13 | 9.52 [4.25, 15.99] |
| er | 21.75 | 16.76 | 4.99 [3.52, 6.61] |
| real | 0.50 | 0.47 | 0.03 [0.00, 0.07] |

BA에서는 39승·16무·45패로, 평균 개선과 사례별 승률의 의미가 다르다. 수면 구조는 97회 동률이며 차이가 작다.

구버전 가중치도 이번과 같은 새 시험 사례 100개에서 다시 평가했다. 이전 변경내역의 50개 사례 평균과 직접 비교하지 않았다.

| 모델 | 훈련 시드 | 구버전 가중치 | 이번 가중치 |
|---|---:|---:|---:|
| GNN | 1 | 3.58 | 0.96 |
| GNN | 2 | 4.53 | 1.17 |
| GNN | 3 | 5.74 | 1.06 |
| DQN | 1 | 5.39 | 1.53 |
| DQN | 2 | 3.63 | 1.23 |
| DQN | 3 | 4.90 | 1.34 |

GNN은 신뢰도순(1.03개)에 가까워졌지만 세 시드 각각의 신뢰도순 대비 95% 구간이 0을 포함하므로 안정적 우위는 확인되지 않았다. DQN은 이전보다 개선됐지만 이번 세 모델 모두 신뢰도순보다 평균 오류가 많았다. marginal(0.66개)은 이번 Spike 비교에서 가장 낮았다.

입자 필터 비교는 같은 marginal 정책에서 추정 방식만 바꿨다. Spike의 평균장 대비 감소량은 −0.11개 [−0.20, −0.03]로 오류가 오히려 증가했다. 100회 중 복구 성공 사건 1건, 최종 평균장 전환 1회가 있었다. 수면 구조의 감소량은 −0.02개 [−0.08, 0.03]였으며 복구·전환 모두 0회였다. 기본 추정은 평균장으로 유지했다.

이번 결과는 검증 사례로 선택된 고정 모델의 시험 성과다. 신뢰구간은 시험 사례 불확실성을 나타내며, 세 훈련 시드 전체의 불확실성을 나타내지 않는다.
