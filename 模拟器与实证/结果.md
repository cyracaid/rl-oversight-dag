## Final method comparison (main result)

| Method | Sink errors | Type |
|---|---|---:|
| No review | 5.90 | traditional |
| Confidence threshold | 2.30 | traditional |
| Structural greedy | 1.80 | traditional (hand-crafted) |
| REINFORCE (MLP scorer) | 1.40 | ours (preliminary) |
| PPO (MLP scorer) | 1.60 | ours (preliminary) |
| **GNN + REINFORCE (fixed budget)** | **1.54 ± 0.46** ✅ | **ours (upgrade)** |
| DQN (value-based) | 5.10 (degenerate) | control |
| CMDP soft-budget (naive) | 4.85 ⏳ | in progress |
| Oracle (upper bound) | 0.00 | upper bound |

> Figure: `results_bar.png` (green = GNN best, orange = CMDP in progress, blue = MLP, gray = traditional/control).

**Key findings:**
- The GNN node scorer's mean (1.54) is comparable to MLP REINFORCE (1.40) and structural greedy (1.80); the best seed hits 1.00. High variance — not a stable win.
- Graph structure has independent value: structural greedy (1.80) beats the confidence threshold (2.30) by 22%.
- DQN degenerates (5.10): under a sparse terminal reward a value function gets no per-step credit, so policy gradient beats value-based methods.
- The CMDP soft budget (PPO-Lagrangian + stop action), naive version, fails (4.85) — see the honest caveats below.

## 1. Real data: errors cluster by type (motivation, Slide 2)

- Data: internal sleep-research dataset, `deidentified_intervalvars_forCD_111325.rds` = **13,990 rows / 237 participants**, daily sleep logs.
- Corrections: 75 manual corrections in `manual_error_correction_updated.csv` (0.54%).
- **order_error = 57/75 = 76%** (not 85.1%; the 85% figure was 57/67, where 67 is the number of rows with a non-empty `error_type` — 8 rows are unlabeled), entropy 0.612, p < 0.0001.
- Conclusion: the error rate is low but the errors cluster strongly by type — so a limited review budget must target the right nodes.

## 2. First version: bandit (honest negative result)

| Strategy | Sink errors |
|---|---:|
| No review / Random 16 / Calibrated threshold / Q-learning / Review-all (upper) | 5.62 / 4.19 / 2.81 / 3.38 / 0.56 |

Diagnosis: reviewing item by item flattens the dependency graph, leaving RL nothing non-trivial to learn; with one type at 76%, the optimal policy collapses into a static rule.

## 3. Reframe: structural value (spike)

Structural greedy (1.80) beats the threshold (2.30) → graph structure has independent value; oracle = 0 means there is room.

## 4. Controls (anti-self-fulfilling)

- Shuffle which items are wrong (break type clustering) → the learning advantage disappears.
- Flatten the graph (break propagation) → the learning advantage disappears.
- Meaning: the advantage comes from the clustering and propagation, not from a rigged simulator.

## 5. Honest caveats (please read)

1. **GNN + REINFORCE multi-seed reproduction (2026-11-09): mean 1.54 ± 0.46 (95% CI [1.08, 2.00]).**
   Per-seed: [1.85, 1.60, 1.35, 1.00, 1.90]. The single-run 1.20 was one seed's good luck. **Mean 1.54 does not significantly beat structural greedy (1.80) or MLP REINFORCE (1.40)** — the honest claim is "comparable to the best baselines, with high variance", not "GNN wins".
2. **GNN + PPO has not converged (~5.60)** — the PPO-on-GNN implementation needs more tuning; it is omitted from the main table.
3. **CMDP soft budget (naive) fails at 4.85** — the stop-action + coverage-constraint credit assignment is too coarse (the whole episode shares one return). It needs a FALCON-style reward-critic + cost-critic, not an episode-level Lagrangian. This is our open problem.
4. All numbers were produced by an AI agent and have not been independently verified; Section 8 of the proposal lists the full checklist.

## 6. Failure analysis: when does RL win, and when does it not?

The multi-seed spread (1.00 to 1.90) is itself a finding: **GNN+REINFORCE sometimes beats every baseline (seed 4: 1.00) and sometimes loses to structural greedy (seed 5: 1.90)**. We do not hide this — it is the interesting part.

Working hypothesis (to be confirmed by the ablation in `rl_ablation.py`): the variance comes from **whether a run happens to learn the confidence signal or falls back to fan-out only**. Seeds that learn both win; seeds that learn only fan-out tie the greedy; seeds that learn neither lose.

This is the X-factor for the talk: **the interesting question is not "does RL win", but "under what conditions does it win"** — clustering strength, budget size, and how noisy the confidence signal is.
