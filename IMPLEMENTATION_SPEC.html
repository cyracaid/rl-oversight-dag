实现规格书

这不是叙事。这是组员照着写代码、复现数字的操作手册。

睡眠数据：与 Maia ten Brink（Stanford Psychophysiology Lab）一年 EMA 合作。
应用：SciForge — Zhangyang Gao（AI4Science, Shanghai AI Lab）。

验证状态：实验代码和数字由 AI 生成，组员尚未独立重跑。未验证项见「验证清单」。

目标与范围

AI 产出一条相互依赖的条目链。人只能审少数几项。错误按类型聚集（76% order_error），没审的错误沿 DAG 往下传，危害到结论才出现。

训练一个策略：下一个审哪个节点（或停），预算内，让更少错误到达结论。

不训练：底层分类器、LLM、视觉模型、splsleep R 包。它们是冻结环境。

RQ1 学到的策略（GNN + REINFORCE / PPO）能不能打赢最好的固定规则（按类型校准阈值、结构贪心）？
RQ2 优势依不依赖图族（模块化 / BA / ER / 真实管道）、预算、置信度信号质量？
RQ3 RL 没赢的时候，剩余误差住在哪（策略 vs 预测器 vs 审阅者漏检率）？

环境规格（冻结）

图族N生成用途
spike（主 RL）804 层 DAG，5 类型，约每节点 2 父GNN / REINFORCE / PPO / DQN
modular50010 簇 × 50，簇内高、簇间接口规模基线
BA500Barabási–Albert m=3，低→高定向无标度 / hub
ER500p=0.015，低→高定向稀疏对照
real21splsleep SCHEMA 手写应用价值

DAG 定向：无向边 {u,v} 若 u<v 变 u→v。去自环。Kahn 必须返回 N 个节点。

类型率：

  • 80 节点 K=5：[0.01, 0.03, 0.08, 0.15, 0.25]
  • 500 节点 K=10：Zipf s=1.2 映到 [0.02, 0.40]
  • 真实管道 K=6：order_error 0.35，其余对齐 75 条纠错

因果传播：P(X_v=0 | X_u=0) = 1 − exp(−λ w)，w ~ U(0.5, 1.5)，λ=0.8（合成）/ 0.9（真实）。审 = do(X_v:=1)。

置信度：logit = (−1.5 若错 else +1.5) − 0.4(P_type−0.15) + N(0,1.2)。消融换噪声 / oracle。

信息泄露铁律：策略永远看不到 X_v、base、coins。只看 type、conf、sink_reach、reviewed、budget。

MDP

要素定义
状态每节点：type one-hot、conf、log1p(sink_reach)/log1p(N)、reviewed? + 剩余预算
动作选下一个未审节点（固定预算主方法没有 stop）
转移审 = do(X_v:=1)，P_catch=0.9 修正，重算下游
奖励r_T = −sink 错误数（稀疏终局）
γ<1；REINFORCE MC 直接用终局

CMDP（形式化；naive 4.85 失败留作消融）：max min J(π) + λ(B − C(π))。d_u=16, d_l=8。

DQN 对照：5.10 退化。别调赢——退化是教学点。

成功：阈值或贪心在新图上赢不审。冻结 GNN vs 重训 GNN 都报。只有重训赢 = domain adaptation 不是 transfer，直说。
