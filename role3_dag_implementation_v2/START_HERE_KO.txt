ZIP을 해제한 뒤 role3_dag_implementation 폴더에서 실행합니다.

1. 설치와 테스트
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v

2. 그래프 하나의 검토 과정을 따라가기
python run_demo.py --family real --policy marginal --particles 1024 --out outputs/particle_demo

3. 배포된 결과 전체 다시 계산하기 (학습 포함)
python reproduce.py

README_KO.md에는 팀원용 API와 지표 설명이, 변경내역.md에는 원본과의 차이와 실험 결과가 있습니다.
기본 비교표는 outputs/benchmark_summary.csv, 각 사례의 선택 순서는 outputs/benchmark_role3.csv에 있습니다.
