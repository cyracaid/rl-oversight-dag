# 수면 데이터 인계 — 헤더·자료형·역할 분담

**한국어 안내가 기본입니다.** [English / 中文 안내](TEAM_HANDOFF.md) · [전체 역할 분담](../TEAM_CLAIMS_KO.md)

팀원은 실제 개인별 기록을 받지 않고도 로더와 검증 코드를 작성할 수 있습니다.
실제 수면 데이터는 접근 권한이 있는 담당자 환경에 남깁니다. 이 인계 문서와
헤더 파일에는 실제 데이터 행, 참여자 ID 값, 정확한 기록 날짜, 자유 서술이나
개인별 수정 내역이 없습니다. 기존 스키마의 통계는 실제 데이터에서 산출한
집계 정보이므로, 공개 허용 여부는 별도로 확인해야 합니다.

## 읽기 규칙과 한계

CSV에는 고유한 자료형이 없습니다. 아래 한국어 필드표의 자료형은 **권장 파싱
방식**이며 원본 시스템의 자료형을 검증했다는 뜻이 아닙니다.

- 결측값은 빈 셀입니다. 결측을 0이나 `-1`로 바꾸지 않습니다.
- 시간 길이는 **분**, `se_percent`는 **0–100**입니다.
- 타임스탬프는 `YYYY-MM-DD HH:MM:SS` 형식의 현지 시각이며 시간대는 미지정입니다.
- `pid`, `row_id`는 식별자입니다. 크기나 순서가 모델 특징이 되면 안 됩니다.
- `StartDate`의 실제 형식은 카드에서 가려져 있습니다. 로컬 원본 확인 후 파서를 정합니다.
- `True`/`False`는 명시적으로 변환합니다. `bool("False")`는 사용하면 안 됩니다.
- 모든 값이 결측인 `error_type`의 자동 추론 `number`는 의미적 자료형이 아닙니다.
- 범주 목록은 잘린 목록일 수 있습니다. 허용값 전체로 간주하지 않습니다.
- 영문표의 반올림된 `true 0%`, `missing 100%` 대신 JSON의 정확한 수치를 확인합니다.

현재 카드는 `output/cleaned_data_final.csv`의 스냅샷입니다. 원본 체크섬과 버전
증빙이 없어 다른 내보내기 파일까지 동일하다고 보장하지 않습니다.
`row_id`는 이 스냅샷에서 고유하다고 보고되어 있습니다. 문서상 조인 키는
`(pid, day_num, row_id)`이며 `(pid, day_num)`만으로 고유하다고 가정하면 안 됩니다.
참여자별 행 수는 최대 75이고 `day_num`은 1–15이므로, 중복을 로컬에서 확인하고
임의로 제거하지 않습니다.

## 정답·특징 분리

초기 예측 인터페이스에서는 JSON의 `label_columns` 8개를 입력 특징에서 제외합니다:
`error_type`, `flag_severity`, `has_correction`, `human_review`, `is_error`,
`is_unusual`, `record_status`, `unusual_type`. 식별자와 정확한 날짜도 제외합니다.
모호성 표시 및 검토 전 플래그를 쓰려면 의사결정 시점에 실제로 존재했는지 먼저
확인합니다. 최종 정제 파일에 있다는 사실만으로 당시 이용 가능했다고 볼 수 없습니다.

이 패키지는 사람이 확인한 수정 정답이나 평가자 일치 여부의 **27/48 분할**을
제공하지 않습니다. 빈 `error_type`이나 합성 입력에서 복원할 수 없습니다.
정답이 필요한 분석은 권한 있는 환경에서 수행하고, 승인된 집계 결과만 공유합니다.
예측 평가의 학습/시험 분할은 참여자 단위로 하여 같은 사람이 양쪽에 섞이지 않게 합니다.

## 담당별 입력과 산출물

| 담당 | 받는 자료 | 제출할 산출물 |
|---|---|---|
| 1번: PM·검토 | 인계 패키지와 실험 보고서 | 주장 → 스크립트 → JSON → 그림 출처표. 미검증 숫자 차단 |
| 2번: 학습 실험 | 합성 DAG 생성기와 실험 프로토콜, 인터페이스 스키마 | 전체 시드 결과·체크포인트·실측 비교. BC 결론을 미리 가정하지 않음 |
| 3번: 환경 | 스키마·합성 입력 생성기·N=21 파이프라인 코드 | 로더·검증기, 단위·결측 검사, DAG 정의, 재현 로그 |
| 4번: 기준선·대조 | 동일한 합성 입력과 그래프 평가 규칙 | 동일 그래프·난수의 기준선/대조 결과. 정답 제공 전 정답 의존 분석 금지 |
| 5번: 데이터 인터페이스·서술 | 스키마 패키지, 허용된 경우 로컬 원본 접근 | 원본 타입·정의 확인, 필드 계약 유지, 승인된 집계 근거 전달 |

전체 역할 문서에는 이전 실험 상태가 남아 있습니다. **BC 1.14 대 교사 1.15는
표와 JSON이 불일치하므로 재현 대기**입니다. Credit assignment는 가설이며 BC만으로
입증되지 않습니다. 경계 실험 코드와 사전등록은 로컬 검증 중이고 이번 인계에는
포함하지 않습니다. 이 문서는 새 실험 결과를 주장하지 않습니다.

## 팀원 실행 방법

저장소 루트에서 실행합니다. NumPy가 필요합니다.

```bash
python3 tools/make_fixture.py --rows 500 --seed 0 --out schema/fixture_sleep.csv
```

생성 파일은 합성 개발 입력이며 Git에서 제외됩니다. 로더 연결 확인에 사용합니다.
실제 결합분포·정답·참여자별 일자 구조·모든 자료형을 보존하지 않습니다. 완전한
밤 블록의 시간 순서는 일관되지만 다른 독립 생성 필드까지 보장하지 않습니다.
`StartDate`가 비어 있거나 전체 결측 열이 float로 추론될 수 있습니다.
**논문·슬라이드의 수치나 임상 검증의 정답으로 사용하지 않습니다.**

정상 기록의 시간 순서 및 TST/TIB/SE 관계는 검증 목표입니다. 실제 원시 기록이나
오류 기록이 모두 이를 만족한다는 뜻이 아닙니다. WASO 등 파생값 정의는 원본
파이프라인과 대조해야 합니다. 기존 문서의 외부 `splsleep/SCHEMA.md`는 이 저장소에 없습니다.

완료 기준: 헤더 39개 이름·순서 유지, 결측 보존, 분 단위 유지, 불리언 올바른 파싱,
정답 누수 없음, 합성 입력에서 얻은 수치의 발표 사용 없음.
